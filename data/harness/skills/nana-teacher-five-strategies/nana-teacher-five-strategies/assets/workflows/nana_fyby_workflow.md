# 负阴抱阳选股工作流

对应选股器：`nana_fyby_xg.txt`  
研究底稿：`负阴抱阳.pptx`  
周期：日线收盘后运行；公式选择“次日确认”，不把假阴线本身直接当买点。

## 1. 选股器做了什么

- 显性负阴抱阳：高开至少 1%、收盘低于开盘但仍高于昨日收盘，且日均成交价高于昨日收盘。
- 隐性负阴抱阳：收盘未站上昨日收盘，但日均成交价仍高于昨日收盘，捕捉盘中承接强于 K 线外观的情况。
- 假阴日量能限制在前日 1.1 倍以上、20 日均量 3 倍以内、换手率不超过 20%，排除高位对倒式巨量。
- 只在次日缩量企稳或反包站上假阴开盘价，并通过 MACD/KDJ 之一确认时输出。

## 2. 每日执行

1. 收盘后运行 `nana_fyby_xg`，回看前一日假阴线的开盘价、最低价和成交量。
2. 检查假阴线是否位于底部/上升初期、平台突破或 5/10 日线支撑附近；高位累计涨幅过大直接剔除。
3. 次日若缩量不破前日低点并站回假阴开盘价，才列入可交易清单；放量下跌不做“抄底”。
4. 放量突破假阴最高价可作为二次加仓点，首仓仍不超过计划仓位 20%-30%。
5. 假阴最低点下方 3% 或关键平台下方取更严格者作为止损参考。

## 3. 跨策略共振

若假阴反包候选同时命中独立交付的“黄金双响”选股器，可视为“前炮-洗盘-后炮”共振；这不替代第五套公式。

## 4. 失效与退出

- 次日不能缩量企稳，或 3-5 日内不能重新站上假阴实顶，形态降级。
- 回撤超过 30%、连续跌破 5/10 日线，或出现高位巨量长上影，按弱庄/出货处理。
- 所属板块连续两日跑输大盘且龙头跌停时，即使个股未破位也减仓。

## 5. 人工复核边界

隐性形态需要分时均价线和量波，公式只用日线成交额近似筛选；Level-2 大单、板块联动和公告催化必须在通达信界面或原始公告中另行核验。
