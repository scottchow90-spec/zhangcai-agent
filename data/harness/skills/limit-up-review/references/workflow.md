## 唯一入口

正式业务执行只允许：

```powershell
python D:\C盘转移\日志\codex\skills\limit-up-review\scripts\codex_entry.py run
```

用户参数只能跟在 `run --` 后显式传入。`info` 与 `selftest` 仅用于检查，不得代替正式执行；其余脚本只能由该入口按锁定顺序内部调用，不得临场改入口、改脚本或改用其他技能。

正式业务历史目录固定为 `$CODEX_HOME/business_data/limit-up-review`；指定 `out_dir` 的隔离运行只能在该 `out_dir` 内写入。通用 Codex 记忆目录不得保存任何涨停复盘业务产物。

## 状态机

每个阶段只接收上一阶段已验证的结构化产物。阶段结果只能是：

- `CLEAN_PASS`：本阶段必需字段、证据和语义约束全部通过。
- `INSUFFICIENT`：允许保留事实，但证据不足以形成相应判断；必须降低置信度或删除候选。
- `BLOCKED`：官方候选池、集合一致性、时间口径、关键证据或硬闸失败，禁止继续渲染和交付。

任何缺失值都写为 `UNAVAILABLE`，同时记录缺失原因、影响字段和置信度上限；禁止把缺失填成 `0`。

## 阶段 0：运行契约与时间锁

1. 锁定目标交易日、数据截止时间、时区、最新可用交易日和执行参数。
2. 读取并校验 `SKILL.md`、`references/business_spec.md`、本文件、`TEMPLATE.md` 与工作流合同。
3. 为本轮建立唯一 `run_id`，所有后续事实、判断、预测和证据文件绑定同一 `run_id`。
4. 若目标日不是已完成收盘的有效交易日，或来源时间晚于分析截止时间却未标注，立即 `BLOCKED`。

## 阶段 1：证据采集与候选宇宙

1. 当日官方涨停池是唯一原始候选宇宙；原始集合完整留证后，对名称带退市标识的股票执行硬剔除，候选、观察池和个股结论都只能来自剔除后的官方合规池。
2. 全 A、指数、行业、概念、炸板、跌停、历史涨停池及历史行情可作为分析或对照宇宙，但不得向候选宇宙新增股票。
3. 每条原始证据记录 `evidence_id`、来源、采集时间、数据时间、字段口径和内容哈希。
4. 至少覆盖：市场宽度、指数与成交、涨停与连板结构、炸板与跌停、方向映射、量价、资金、公告/政策/新闻催化和历史数据。
5. 官方涨停池缺失、为空、关键标识缺失或集合无法确认时，立即 `BLOCKED`，禁止用缓存、人工名单或阈值猜测替代；原始池、退市剔除集合和合规池差集不闭合时同样阻断。

## 阶段 2：标准化、质量矩阵与缺失管理

1. 统一证券代码、名称、交易日、方向标签、金额单位、百分比和时间字段。
2. 对每个分析域计算来源新鲜度、字段覆盖率、冲突数、异常数与可追溯率。
3. 来源冲突不得静默覆盖；保留冲突双方、采用规则和对结论的影响。
4. 关键域缺失时形成 `data_gap`，结论置信度不得高于该域允许的上限。
5. 官方候选集合不一致、重复代码、未来数据混入或关键事实不可追溯时，立即 `BLOCKED`。

## 阶段 3：历史基线

1. 使用可获得的 20/60 个交易日同口径数据建立市场宽度、涨停数、炸板率、连板晋级率、最高板、方向集中度、成交和资金覆盖基线。
2. 当前值同时给出绝对值、历史分位、相对基线偏离和样本量；不得只凭单日大小下结论。
3. 历史窗口不足5期时写 `UNAVAILABLE`；市场、结构和风险 thesis 必须降为 `INSUFFICIENT/LOW`，禁止用任意阈值或经验分数冒充历史校准。
4. 所有基线只能使用分析截止时间之前的数据。

## 阶段 4：市场结构判定

综合而非罗列以下维度：

- 指数、成交与全市场涨跌宽度；
- 涨停、炸板、跌停的收益/亏损效应；
- 首板、二板、三板及以上的梯队、晋级和断层；
- 最高板、封板质量、开板回封、量价与资金一致性；
- 当前状态相对 20/60 日基线的位置。

输出市场状态、支持证据、最强反证、置信度、适用边界和失效条件。宽度、梯队、封板质量彼此背离时必须显式描述分歧，不得压成一句固定强弱判断。

## 阶段 5：方向论证

方向不是“所属行业计数”的同义词。每个方向必须形成一张 thesis card，至少包含：

- 方向定义与样本映射；
- 广度、连续性、梯队高度、封板质量、资金一致性和相对基线；
- 催化事实及其发生时间，或明确 `UNAVAILABLE`；
- 内部分化、同题材炸板/跌停、资金背离等反证；
- 结论状态、置信度、置信度依据和失效条件。

“核心方向”至少需要广度、连续性、封板质量、催化可信度、资金一致性五维中的三维共同支持，且连续性和催化可信度不可缺失。未满足时只能标记为待确认或证据不足。

## 阶段 6：个股角色与观察优先级

1. 个股只从官方涨停池产生，先判定其在方向和梯队中的角色，再决定是否进入观察池。
2. 可用角色包括：高度锚、方向核心、容量承接、首板确认、补涨跟随、孤立涨停和脆弱样本；角色必须有字段证据，不得由股票名称或模板预设。
3. 每个观察对象至少需要三个独立的行级证据维度，并写明“为何现在观察”、确认条件、排除条件、失效条件、主要反证和同板级横截面对比；聚合指标不能替代个股字段证据。
4. 排序分数只用于内部排序；未经历史校准的分数、权重和阈值不得成为可见结论，也不得单独决定观察优先级。
5. 证据不足的股票保留在全量事实表，但不得进入重点观察结论。

## 阶段 7：Claim Graph

所有分析判断写入 `business_result.json` 的 claim graph，节点分为 `FACT`、`INFERENCE`、`HYPOTHESIS`：

1. 每个非事实节点必须引用证据 id，并标明 claim_type、至少两步推理链、最强反证及其替代解释、置信依据与失效条件。
2. 结论状态仅允许 `SUPPORTED`、`CONTESTED`、`INSUFFICIENT`、`REJECTED`。
3. 推断至少需要两个相互独立的证据维度；单一计数、单一资金流或单一涨停不能推出方向性结论。
4. 因果判断必须同时满足：事件先于价格反应、事件与方向语义匹配、存在横截面响应、替代解释已检查。否则只能表述为相关或假设。
5. 摘要必须同时包含主结论、最强反证、置信度依据和失效条件，禁止只写正向理由。

## 阶段 8：四分支次日情景树

情景树固定覆盖：

1. `STRENGTHEN`：主方向加强。
2. `ROTATION`：方向轮动或高低切换。
3. `FAILURE`：结构走弱、核心断板或亏钱效应扩散。
4. `EXOGENOUS_SHOCK`：公告、政策、海外或突发事件改变原假设。

每个分支必须包含盘前、开盘、盘中和收盘检查点，并给出至少两个可观察触发器、对应行动/回避原则、失效条件和需要降级的 claim。行动只能是条件化观察与风险控制，不得写无条件买卖指令。未完成历史校准前不得给情景概率。

## 阶段 9：冻结预测账本

在渲染前冻结本轮预测账本并写入 `business_result.json`：

- run id、as-of 时间、预测对象、观察期限；
- 前提条件、预期可观察结果、确认与失效条件；
- 对应 claim id、情景分支和风险边界；
- 冻结时间与内容哈希。

账本必须逐条覆盖 thesis 和观察对象；哈希覆盖账本条目，而不只覆盖标题、情景和名单。

冻结后不得按次日结果回写原预测；修订只能新增带时间戳的版本并保留原哈希。

## 阶段 10：业务语义硬闸

渲染前必须逐项验证：

1. 候选、观察池代码都是官方涨停池子集，且全量事实表与官方池集合完全一致。
2. 所有可见判断可追溯到本轮证据，来源时间不晚于 as-of。
3. 关键判断具备历史基线、至少两个证据维度、反证、置信度依据和失效条件。
4. 每个重点观察对象具备角色、三个独立证据维度、确认和排除条件。
5. 四分支情景树与冻结预测账本完整。
6. `UNAVAILABLE` 未被写成零；数据缺口已传导到置信度和结论状态。
7. 未校准分数没有直接进入可见结论。
8. `business_result.json` 中不存在模板默认结论、固定措辞或无证据兜底判断。
9. 可见 Markdown、CSV、观察池和 Word 不含退市股代码/名称，拉丁字母命中均为零。

任一项失败即 `BLOCKED`；不得先生成 Word 再用文字润色掩盖分析缺口。

## 阶段 11：最后渲染

只有阶段 10 通过后，才允许将 `business_result.json` 映射为 Markdown、CSV、观察池和 Word。模板只负责结构与样式，不得：

- 新增 claim、候选、情景或结论；
- 把 `INSUFFICIENT` 改写成确定判断；
- 删除反证、失效条件或数据缺口；
- 使用模板默认结论、固定措辞或兜底判断。
- 显示退市股，或把内部英文状态、英文情景键、英文字段名及行业缩写直接写入正文。

## 阶段 12：产物与证据终检

终检验证候选集合、分析结果、可见产物和哈希快照属于同一 run id，并检查文件存在、结构完整、引用闭合和禁止措辞。任何失败都返回 `BLOCKED`，不得交付半成品。

## 阶段 13：T+1 / T+N 校准

后续复核只对照冻结预测账本，不得凭结果重写原结论。至少评价：

- 方向延续率、连板晋级率、相对基准表现；
- 观察对象的最大有利/不利偏移（MFE/MAE）；
- 触发器、失效条件和四分支情景的命中情况；
- 风险提示召回率、误报与漏报；
- 分数或排序规则在足够样本上的区分度与稳定性。

复核结果进入新的校准记录，用于降权、停用或重估规则；样本不足的指标保持“未校准”，不得升级为可见结论。
