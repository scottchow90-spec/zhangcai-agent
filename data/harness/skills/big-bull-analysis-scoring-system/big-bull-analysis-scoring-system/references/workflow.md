# 合并执行流程

## 模式选择

1. 用户提供股票代码或明确要求个股分析时，运行`analyze`。
2. 用户提供自定义板块、要求评分排名或没有额外参数时，运行`score-research-composite`。
3. 不得同时运行两个模式后拼接结果；每次运行只对应一个明确业务目标。
4. 用户要求预测型三公式综合评分时，先以`backtest-composite`执行科学验收；只有结果为`PREDICTIVE_PASS`时才允许安装正式模型并以`score-composite`生成最新横截面排名。
5. 用户明确不要求或禁止回测时，直接运行`score-research-composite`，不得先跑回测，也不得改走旧五维板块评分。
6. 三公式综合评分固定且仅使用大牛线16项、飞龙在天10项、庄家资金监控4项，共30项。每套体系先形成独立子分，再用三体系权重、共振加分和分歧扣分形成唯一总分。
7. 研究型结构评分固定使用大牛线40%、飞龙在天35%、庄家资金监控25%；预测型评分使用正式模型中的三体系权重。两种模式的三体系权重都必须严格合计100%。
8. 指定自定义板块时，必须固定使用通达信`market=23`沪深300作为唯一参考母体，排序去重后计算百分位；板块股票只作为待评分目标取数，禁止进入或改写百分位母体。
9. 每次评分必须写出评分口径ID、统一评分日、母体SHA-256、模型SHA-256和公式目录SHA-256。多板块结果必须通过“同口径、同日期、同母体、同模型、同公式、同股同分”代码硬闸。
   固定入口为`verify-cross-board-consistency --ranking-json <一> --ranking-json <二>`，不得以人工目测替代。
10. 30项综合评分由本技能独占持有；飞龙在天和庄家资金监控是被吸收组件，不得在同一综合请求中再次作为独立技能执行。

## 分析模式

1. 调用合并技能内的`daniuxian_analysis.py`。
2. 读取本机通达信日线和大牛线运行态。
3. 输出固定十六项分析。
4. 将完整文字报告保存为`analysis_report.txt`。
5. 将统一执行摘要保存为`result.json`。

## 固定30项评分模式

1. 调用合并技能内的`three_formula_composite_backtest.py --score-only --research-structural`。
2. 默认读取“黄金点火”自定义板块。
3. 在通达信`market=23`沪深300固定参考母体上统一评分日，使用中点秩计算百分位；常量横截面映射为50分并保留正业务权重。
4. 仅在30项真实值全部有限时计算16＋10＋4三体系子分和40%＋35%＋25%综合分。缺一项即整单失败；任何零权重或贡献不可复算同样失败。
5. 使用固定母体分位生成未来5至10个交易日规则型结构预测和失效条件，输出`forecast_is_probability=false`与`score_is_probability=false`。
6. 输出最新排名JSON/CSV、30项贡献CSV、完整报告、8K海报、`1920×1080`完整适配预览和`result.json`。
7. 海报必须通过尺寸、字号、亮度、文字和全量覆盖检查；海报行数、评分源股票数、通达信板块成分数必须完全相等，禁止静默截断。

## 历史五维兼容边界

- `score-board`、`score`和`评分`不是生产默认入口。
- 仅在用户明确要求复核历史五维结果时，才可同时提供`--legacy-five-dimension-compat`运行。
- 缺少显式兼容标识必须阻断；历史五维结果不得命名为30项综合评分，也不得与30项结果比较后冒充同一口径。

## 数据与模型边界

- 本机通达信是核心数据来源。
- 数据缺失、运行态不可用或日期无法统一时明确停止，不以旧结果冒充当前结果。
- 三公式综合评分固定使用`Asia/Shanghai`时区执行评分日期硬闸。北京时间星期一至星期五，统一评分日必须严格等于北京时间当天；日期不一致时必须在最新排名JSON、排名CSV、30项贡献CSV和排名报告写出前终止，并清除同一输出目录中的旧排名产物。
- 三公式综合评分报告必须显示股票名称和代码、板块排名、全市场排名、总分及三项拆解、三体系子分、逐股结论，以及每只16＋10＋4固定明细。任何名称、字段、结论、股票或明细缺失均阻断。
- 模型必须在统一评分日确定后仅以固定参考母体横截面构建；板块股票不得改变权重或单项百分位。30项全部具有真实来源、有限原始值、正业务权重和逐项贡献。
- 每条30项贡献必须同时保存原始值、百分位、体系权重、体系内权重和逐项贡献；任一缺失或不可复算时必须阻断交付。
- 禁止以零权重、中性弃权或固定体系50分掩盖缺失子系统；常量观测仅以中点秩50参与。
- 综合结论只能使用固定母体分位表达相对位置；综合分不是上涨概率，不得以未经校准的绝对分数阈值解释未来涨跌。
- 三公式回测必须统一使用本机通达信`front`前复权日线计算三套公式特征和收益标签；不得混用前复权特征与未复权收益。
- 10日标签在训练/验证和验证/测试边界各净化至少10个交易日；覆盖率、区分度和零权重选择只允许使用训练期数据。
- 独立样本外至少40个再平衡日，样本外明细和分期文件必须非空；报告必须给出平均IC、5日和10日Top10%超额的Newey-West 95%区间、预声明经济门槛及等权基准。
- 三公式综合评分只接受状态为`CLEAN_PASS`且预测状态为`PREDICTIVE_PASS`的正式分层模型：历史回测固定30项完整、每套体系内部权重各自等于100、三体系模型权重总和等于100，且共振与分歧参数均存在。
- `PREDICTIVE_REJECTED`时正式模型文件必须`model=null`且`installed_model=null`。审计结构模型只能作为阻断诊断写入回测证据，禁止安装、加载或生成预测型当前评分。
- `score-research-composite`固定输出`scoring_mode=RESEARCH_STRUCTURAL`、`research_only=true`、`prediction_authorized=false`，按40%/35%/25%执行研究型结构评分，不安装预测模型、不产生预测授权。

## 固定产物

- 所有模式：`result.json`
- 分析模式：`analysis_report.txt`
- 历史五维兼容模式：`ranking.json`、`poster.png`
- 三公式回测：回测报告、回测证据、正式模型、样本外明细、样本外分期
- 三公式综合评分：最新排名JSON/CSV、30项贡献明细CSV、最新排名报告、8K海报及`1920×1080`完整适配预览
- 评分结构海报：固定30项、三体系权重和0至100分值；同时生成8K成品和1920×1080适配预览。当前预测模型未通过时只能标注结构展示，不得宣称模型已启用。
