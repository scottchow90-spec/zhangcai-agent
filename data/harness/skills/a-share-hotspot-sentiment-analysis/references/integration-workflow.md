# A股舆情来源优化合并合同

## 架构

采用“一个原始证据池、多个派生视图”，不复制执行其他技能，不把同一事件重复写成多份证据：

1. 八站舆情、主流财经和公告仍是滚动 72 小时直接证据。
2. 连板网、通达信、短线侠仍是最近三个完整交易日的独立盘面验证证据。
3. 白猫每日资讯的早盘、午盘、收盘结果改为统一事件池的时间切片视图；视图不增加事件权重。
4. 短线市场情绪结果改为统一盘面证据上的两层阶段视图，分别保留中级周期和短线情绪阶段、置信度、冲突及反证；禁止折算成加权总分。
5. 生意社只读取本轮官方页面证据 `business_society.json`。优先 Chrome；当前会话未暴露 Chrome 能力时，允许受限的官方公开页只读通道。商品事件只有在采集时间不超过 45 分钟、滚动 72 小时内、来自 `100ppi.com` 或 `ppi.cn` 官方域名，并与本轮 A 股事件自然发现的主题发生动态匹配时才能进入统一事件池。

## 统一事件模型

每条进入分析的事件使用 `A_SHARE_SENTIMENT_UNIFIED_EVENT_V1`，至少包含：

- `canonical_event_id`：规范 URL、时间窗、日期和正文生成的稳定标识；
- `origin_streams`：直接证据或派生来源族，不把派生视图伪装成新来源；
- `evidence_tier`、`fact_strength`：区分公告、产业官方数据、财经媒体、盘面结构和社区信号；
- `a_share_relevance`：接受状态、原因、动态匹配词及原 A 股证据；
- `provenance`、`evidence_sources`：保留所有独立出处，但一组重复事件只保留一个规范事件；
- `conflict_ids`：同主题正反证据并存时写入冲突登记，不做正负抵消。

## 去重、聚类和冲突

1. 先按规范 URL 精确去重，再在同时间窗、共享自然主题的前提下做高阈值近似文本去重；跨午夜但发布时间相距不超过 12 小时的重复不得因日期字段不同而漏合并。
2. 跨源重复只增加“独立佐证来源”，不得增加事件次数和评分权重。
3. 主题只从本轮事件文本自然发现；生意社映射也只使用本轮主题，不维护固定板块池或固定结论池。
4. 同主题正负证据同时存在时保留双方原文、来源和事件标识，生成冲突登记；报告写“分歧”及失效条件，不得平均成中性事实。
5. 社区信号只能说明热度、分歧和参与者情绪，不能单独证明公告、政策、监管、订单、业绩或商品价格事实。

## 排除边界

- 顶级智库观点不进入此统一事件池。
- 黄金情报系统和比特币新闻情报技能不修改、不执行、不引用、不形成运行依赖。
- “黄金点火”等 A 股策略名称不是黄金行情技能，但本流程也不调用该策略。
