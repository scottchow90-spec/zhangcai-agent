## 子系统穷举

### 1. AAA 快慢 EMA 趋势差

```tdx
AAA:EMA(CLOSE,5)-EMA(CLOSE,30),NODRAW;
```

含义：5 日 EMA 与 30 日 EMA 的趋势差。不是直接资金流，而是短中期价格趋势差。

解释规则：

- `AAA > 0`：短期均线仍在中期均线上方，价格结构仍有多头残留。
- `AAA 上升`：短期趋势相对中期趋势增强。
- `AAA 下降`：短期趋势相对中期趋势走弱。
- `AAA 跌近 0`：短期优势接近耗尽。

### 2. DDD 买方意向信号线

```tdx
DDD:EMA(AAA,5),NODRAW;
```

含义：AAA 的 5 日 EMA，类似 MACD DEA。

解释规则：

- `AAA > DDD`：趋势差增强，买方意向有加速。
- `AAA < DDD`：趋势差减弱，买方意向转弱。
- `DDD 下行`：趋势差平滑中枢下降。

### 3. 买方意向主输出

```tdx
买方意向:(AAA-DDD)*2,COLORSTICK,NODRAW;
```

含义：核心动能输出。

解释规则：

- `买方意向 > 0`：AAA 强于信号线，买方动能占优。
- `买方意向 < 0`：AAA 弱于信号线，买方动能转弱。
- 乘以 2 只是显示放大，不改变方向判断。

### 4. 正向买方意向柱 / OUTPUT4

```tdx
STICKLINE(买方意向>0,买方意向,0,3,0),COLORMAGENTA;
```

含义：仅在 `买方意向 > 0` 时画紫红色正向柱。TQ 返回里的 `OUTPUT4` 通常是该条件对应的外显标记，表现为 1/0；强弱仍看 `买方意向` 数值。

解释规则：

- `OUTPUT4 = 1`：有正向买方意向柱。
- `OUTPUT4 = 0`：没有正向买方意向柱。
- 连续为 0：正向游资买方柱连续消失。

### 5. L2 四档资金分层模块 X_1～X_14

```tdx
X_1:=L2_AMO(0,2)/10000;
X_2:=L2_AMO(1,2)/10000;
X_3:=L2_AMO(2,2)/10000;
X_4:=L2_AMO(3,2)/10000;
X_5:=L2_AMO(0,3)/10000;
X_6:=L2_AMO(1,3)/10000;
X_7:=L2_AMO(2,3)/10000;
X_8:=L2_AMO(3,3)/10000;
X_9:=X_1+X_2+X_3+X_4-(X_5+X_6+X_7+X_8);
X_10:=X_1-X_5;
X_11:=X_2-X_6;
X_12:=X_3-X_7;
X_13:=X_4-X_8;
X_14:=CONST(MAX(ABS(X_9),MAX(ABS(X_10),MAX(ABS(X_11),MAX(ABS(X_12),ABS(X_13))))));
```

含义：L2 分档资金内部计算。

- `X_1～X_4`：L2 四档方向 2 金额，除以 10000 换算为万元级。
- `X_5～X_8`：L2 四档方向 3 金额，除以 10000 换算为万元级。
- `X_9`：四档合计净额。
- `X_10～X_13`：四档单档净额。
- `X_14`：总净额和分档净额的最大绝对值常量基准。

硬规则：这些变量全部用 `:=` 定义，是内部变量，不是外显输出。除非后续通过表达式接口或改造公式成功外显，否则只能解释公式含义，不能编造具体数值。

## 科净源样例结论基准

样例：`301372.SZ 科净源`，日期 `20260529`。

- 收盘/现价：35.56
- 昨收：35.80
- 涨跌幅：-0.67%
- 成交额：5527.13 万
- 内盘：8232
- 外盘：7174
- AAA：0.65
- DDD：1.49
- 买方意向：-1.69
- OUTPUT4：0.00

解释口径：

- AAA 仍正但从高位快速回落，趋势差残留但斜率塌缩。
- AAA < DDD，买方动能处于压制状态。
- 买方意向连续多日为负，未重新翻正。
- OUTPUT4 连续为 0，正向买方柱消失。
- 当前不能支持“游资正向进攻状态”的结论。

## 禁止事项

- 禁止把 `X_1～X_14` 未外显数据编造成具体数值。
- 禁止把 `Zjl / TotalBVol / TotalSVol / 内外盘` 直接等同于 `L2_AMO()` 内部变量。
- 禁止因为公式名相近而替换成机构资金监控、庄家资金监控、大牛线、飞龙在天等其他公式。
- 禁止在没有验证 D 盘数据和 TQ 返回的情况下假交付。
