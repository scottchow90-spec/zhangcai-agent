# 硬闸业务规范

name: stock-hard-gate
name_cn: 硬闸
data_source: local input text
primary: scripts/preflight.py

## 输入

- 第一个参数：待执行股票操作的完整计划文本。
- 第二个参数：可选的计划动作名称。
- 无参数：固定适配器提供完整正向 canary，用于执行链验收。

## 必须声明

计划文本必须包含：

- 逐字回读
- 用户原话
- 禁止默认替代
- 禁止任务扩展
- 禁止单源结论
- 禁止热替换
- 输出结构服从用户
- 禁止缩窄范围
- 禁止子代理跑偏
- 禁止假交付

## 公式规范

- 大牛线 → 大牛线4.0
- 旧版带版本号的飞龙公式 → 禁止；唯一合法公式名为飞龙在天
- 机构自检/机构自检监控 → 机构资金监控
- 庄家自检/庄家自检监控/庄家资金监控2 → 庄家资金监控

## 终态

- 全部规则满足：PASS，进程退出码 0。
- 任一规则不满足：BLOCKED，进程退出码非 0，并列出 warnings。
- 不存在静默降级、远程 fallback 或自动转路由。

本技能只检查计划，不读取行情、不执行交易、不操作桌面进程，也不把 canary 当作股票研究结果。
