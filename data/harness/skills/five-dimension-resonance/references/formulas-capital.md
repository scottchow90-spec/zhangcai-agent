# 资金监控三件套公式源码与解读

> 包含：游资资金监控、机构资金监控、庄家资金监控的完整TDX源码、信号字段、强弱分级。

---

## 一、游资资金监控：完整TDX源码

```text
AAA:EMA(CLOSE,5)-EMA(CLOSE,30),NODRAW;
DDD:EMA(AAA,5),NODRAW;
买方意向:(AAA-DDD)*2,COLORSTICK,NODRAW;
STICKLINE(买方意向>0,买方意向,0,3,0),COLORMAGENTA;
X_1:=L2_AMO(0,2)/10000;
X_2:=L2_AMO(1,2)/10000;
X_3:=L2_AMO(2,2)/10000;
X_4:=L2_AMO(3,2)/10000;
X_5:=L2_AMO(0,3)/10000;
X_6:=L2_AMO(1,3)/10000;
X_7:=L2_AMO(2,3)/10000;
X_8:=L2_AMO(3,3)/10000;
X_9:=X_1+X_2+X_3+X_4-(X_5+X_6+X_7+X_8);
X_10:=X_1-X_5;
X_11:=X_2-X_6;
X_12:=X_3-X_7;
X_13:=X_4-X_8;
X_14:=CONST(MAX(ABS(X_9),MAX(ABS(X_10),MAX(ABS(X_11),MAX(ABS(X_12),ABS(X_13))))));
```

本地调用：`tq.formula_process_mul_zb('游资资金监控', stock_list=[code], count=5)`

## 二、游资信号解读

| 字段 | 公式 | 含义 |
|---|---|---|
| AAA | EMA(C,5)-EMA(C,30) | 短线动能差值 |
| DDD | EMA(AAA,5) | AAA的5日平滑 |
| 买方意向 | (AAA-DDD)*2 | 正值=游资做多 |

**强弱分级：**

| 买方意向 | 判断 | 处理 |
|---:|---|---|
| >2 | 强攻击 | 积极参与确认 |
| 0.5-2 | 正向攻击 | 关注是否扩大 |
| 0-0.5 | 弱正向 | 等转强 |
| <0 | 游资退潮 | 谨慎/剔除 |

**冲高回落预警：** 买方意向由正转负 = 游资出货。买方意向持续缩小 = 攻击力衰减。

**X_9全档净流入：** 正值=各档位合计净买入。

**注意：** 游资资金适合判断短线攻击力，不适合单独判断趋势持续性。必须搭配机构资金和飞龙波段使用。

## 三、机构资金监控：完整TDX源码

```text
大单动向:(LARGEINTRDVOL-LARGEOUTTRDVOL)*10000/FINANCE(7),NODRAW;
NOTEXT1:MA(大单动向,10)*3,NODRAW;
STICKLINE(大单动向>0,0,大单动向*(大单动向>0),3,0),COLORMAGENTA;
DRAWGBK(CLOSE>0,RGB(0,0,0),RGB(0,0,0),0,9,0);
X_1:=(L2_VOL(0,0)-L2_VOL(0,1))*VOL/10000;
X_2:=(L2_VOL(1,0)-L2_VOL(1,1))*VOL/10000;
X_3:=(L2_VOL(2,0)-L2_VOL(2,1))*VOL/10000;
X_4:=(L2_VOL(3,0)-L2_VOL(3,1))*VOL/10000;
机构大单进:EMA(X_1,20)*60/CAPITAL,NODRAW,COLORRED,LINETHICK4;
STICKLINE(机构大单进>0,0,机构大单进*(机构大单进>0),3,0),COLORMAGENTA;
机构大单出:机构大单进<0,NODRAW,COLORLIGREEN;
大户大单进:EMA(X_2,20)*60/CAPITAL,NODRAW,COLOR00AACC;
X_5:=EMA(X_3,20)*60/CAPITAL;
散户资金进:EMA(X_4,20)*60/CAPITAL,NODRAW,COLORGRAY,LINETHICK4;
小单资金出:大户大单进<0,NODRAW,COLORLIBLUE;
中轴线:0,POINTDOT,COLORWHITE,LINETHICK3;
```

本地调用：`tq.formula_process_mul_zb('机构资金监控', stock_list=[code], count=5)`

---

## 四、机构信号解读

| 字段 | 公式 | 含义 |
|---|---|---|
| 大单动向 | (超大单买入-卖出)*10000/总股本 | 大资金方向 |
| 机构大单进 | EMA(超大单净买入,20)*60/CAPITAL | 机构净买入 |
| 机构大单出 | 机构大单进<0→1 | 机构卖出风险⚠️ |
| 大户大单进 | EMA(大单净买入,20)*60/CAPITAL | 大户跟买 |
| 散户资金进 | EMA(小单净买入,20)*60/CAPITAL | 散户流向 |
| 小单资金出 | 大户大单进<0→1 | 小单离场信号 |

**强弱分级：**

| 机构大单进 | 判断 |
|---:|---|
| >2 | 强机构参与 |
| 0.5-2 | 机构参与 |
| 0-0.5 | 弱参与 |
| <0 | 机构转弱 |

**关键判断：**
- 机构大单进>0且扩大 = 机构持续买入。
- 散户资金进<0 = 筹码从散户向机构集中（利多信号）。
- 机构大单出=1 = 机构转卖出，风险升高。
- 机构强+游资弱 = 趋势型，等回踩/突破；机构弱+游资强 = 短线型，需看次日承接。

## 五、庄家资金监控：完整TDX源码

```text
B1:=(HHV(H,N)-C)/(HHV(H,N)-LLV(LOW,N))*100- M;
B2:=SMA(B1,N,1)+100;
B3:=(C-LLV(L,N))/(HHV(H,N)- LLV(L,N))*100;
B4:=SMA(B3,7,1);
B5:=SMA(B4,5,1)+100;
B6:=B5-B2;
控盘程度:(IF(B6>N1,B6-N1,0))*3.5,COLORYELLOW;
控盘度:100,COLORRED;
STICKLINE( 控盘程度,0,控盘程度 ,3,0 ),COLORMAGENTA;
STICKLINE( 控盘程度 AND 控盘程度>100,100,控盘程度 ,3,0 ),COLORMAGENTA;
```

本地调用：`tq.formula_process_mul_zb('庄家资金监控', stock_list=[code], count=5)`

## 六、庄家信号解读

| 字段 | 公式 | 含义 |
|---|---|---|
| B1 | (HHV(H,N)-C)/(HHV(H,N)-LLV(L,N))*100-M | 股价距高点越近B1越高 |
| B2 | SMA(B1,N,1)+100 | B1的N日平滑 |
| B3 | (C-LLV(L,N))/(HHV(H,N)-LLV(L,N))*100 | 股价距低点越近B3越高 |
| B4 | SMA(B3,7,1) | B3的7日平滑 |
| B5 | SMA(B4,5,1)+100 | B3的双重平滑 |
| B6 | B5-B2 | 核心差值：支撑-压力 |
| 控盘程度 | IF(B6>N1,B6-N1,0)*3.5 | 控盘量化（0=无显著控盘，非数据缺失） |
| 控盘度 | 100(固定) | 满格参考线（固定值，非实时数据） |

**强弱分级：**

| 控盘程度 | 判断 | 说明 |
|---:|---|---|
| >100 | 高控盘 | 庄家正在拉升 |
| 50-100 | 控盘增强 | 主力吸筹中 |
| 0-50 | 初步控盘 | 有庄但力度弱 |
| 0/None | **无显著控盘** | ⚠️ 这是有效数据！B6未超阈值N1，不是"数据缺失" |

> **重要：控盘程度=0或None ≠ 数据缺失。** 它表示该股当前无显著庄家控盘。只有TQ整体返回ErrorId时才叫数据缺失。

**关键判断：**
- 控盘程度持续上升 = 主力吸筹增强。
- 控盘程度下降 = 控盘减弱，需警惕。
- 控盘强但飞龙未转强 = 潜伏期，不提前看多。
- 控盘强+大牛线点火+飞龙主升 = 高质量筹码结构。

## 七、云端使用说明

- 游资买方意向在无TQ时可从L2数据计算或从行情量价关系手动判断。
- 机构资金需L2逐笔数据，云端无法直接获取时可用公开的北向资金、龙虎榜替代。
- 庄家控盘程度在无TQ时可从股东户数变化、成交量分布、价格震荡区间近似判断。
- 三个公式在五维体系中的角色：游资看攻击、机构看承接、庄家看筹码。
