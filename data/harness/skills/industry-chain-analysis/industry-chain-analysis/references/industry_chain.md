# 产业链分析方法

## 目标

定位价值创造和利润沉淀的环节，解释供需与周期位置，并用主营、订单、产能和财务证据核验受益公司。不要只罗列概念股。

## 十步流程

| 步骤 | 要回答的问题 | 最低证据要求 |
|---|---|---|
| 1. 范围 | 研究对象、地域、市场和时间范围是什么？ | 明确口径与截止时间 |
| 2. 全景 | 上游、中游、下游和关键服务环节是什么？ | 至少一项权威产业分类来源 |
| 3. 路线 | 技术路线或产品分类如何分叉？ | 路线定义、量产状态和适用场景 |
| 4. 价值链 | 收入、毛利或议价权在哪些环节沉淀？ | 公司财报、行业统计或可复核估算 |
| 5. 上游 | 资源、原料、设备的稀缺性与成本约束是什么？ | 价格、产量、进口依赖或集中度 |
| 6. 中游 | 产能、良率、成本和竞争格局如何？ | 产能/利用率、份额或代表公司披露 |
| 7. 下游 | 需求来自哪里，渗透率和价格弹性如何？ | 销量、出货、渗透率或客户结构 |
| 8. 周期 | 当前处于出清、修复、扩张还是过热？ | 价格、库存、开工率和新增产能中的至少两类 |
| 9. 政策 | 政策改变了需求、供给、成本还是准入？ | 政策原文与生效时间 |
| 10. 受益核验 | 哪些公司受益，证据链是否闭合？ | 主营占比，加上订单/产能/财务兑现中的至少一项 |

## 价值链判断

按以下顺序判断，不把任一单指标当作结论：

1. 利润水平：毛利率、净利率和资本回报是否稳定。
2. 供给约束：资源、设备、认证、良率或扩产周期是否形成约束。
3. 议价权：价格变化能否传导，客户集中是否削弱议价权。
4. 资本强度：高利润是否被持续资本开支和营运资金占用抵消。
5. 可持续性：技术替代、政策变化和新增供给是否会削弱优势。

## 周期判断

| 状态 | 常见证据组合 | 研究含义 |
|---|---|---|
| 出清 | 价格承压、库存高、开工率低、亏损扩散 | 等待供给退出和库存拐点，不把低估值等同于低风险 |
| 修复 | 价格企稳、库存下降、开工率回升 | 核验修复是否传导至现金流和订单 |
| 扩张 | 需求增长、盈利改善、产能有序释放 | 关注份额、成本与执行力 |
| 过热 | 价格急涨、集中扩产、估值透支 | 压力测试需求和新增供给，避免线性外推 |

周期状态必须由当前回合证据判断。历史案例只能解释方法，不能复用其数值或状态。

## 真伪受益核验

对每家公司逐项记录：

- 标的身份：代码、公司名、交易市场和币种。
- 业务映射：受益业务名称及最新可得主营收入占比。
- 落地证据：订单、客户、产能、良率、认证、项目进度或收入兑现。
- 财务传导：收入、毛利、现金流或资本开支是否与逻辑一致。
- 反证：公告澄清、业务占比过低、无产能/无订单、依赖单一客户等。

分类规则：

- `SUPPORTED`：业务映射明确，且至少一项落地证据可核验。
- `WATCH`：逻辑合理，但兑现证据不足或时间尚早。
- `AVOID`：存在明确反证，或概念关联不能传导到主营。
- `INSUFFICIENT_EVIDENCE`：关键数据缺失，不能判断。

原包中的 15%/5% 等占比仅可作为筛查提示，不是跨行业通用硬阈值。必须结合行业结构、会计口径和来源质量解释。

## 输出结构

1. 分析边界与截止时间
2. 产业链全景和技术分类
3. 价值链及证据强度
4. 上中下游拆解
5. 供需、周期与政策
6. 核心受益环节
7. 受益公司核验表
8. 结论与跟踪条件
9. 风险和未验证项
