# 掌财智能体网页 Demo

本项目是 Windows 股票智能体的网页原型，不是已接通 53 项技能的生产版本。

## 运行

Node.js >= 22.13，使用项目现有 pnpm 锁文件。

```text
pnpm install
pnpm dev
pnpm build
```

打开开发服务打印的 Local 地址。默认端口被占用时会自动使用其他端口。

## 数据

`lib/market.json` 是从用户指定的 `C:/new_tdx_mock` 只读导入的历史日线快照。数据日期为 2026-09-04，包含 5,548 只同日股票、4 只指数及部分近期日线。它不是实时行情，原始真实性未独立核验，涨跌幅未进行除权参考价校验。

`lib/skills.json` 来自迁移包权威 53 项目录；保留稳定 ID、中文别名和页面归类。依赖提示为静态分析结果，不替代原技能完整合同。

用户自选仅写入当前浏览器 localStorage。摘要由页面确定性计算，未调用模型。资金数据和完整策略执行未伪造结果。可选 WebMCP 工具只打开现有股票快照，不执行分析或交易；工具专门验证环境当前不可用。

## 正式版边界

未来 Windows 版应将数据访问替换为本地受控服务，通过 DeepSeek Harness 股票插件调用经适配的 Python 根入口。浏览器内不存放 API 密钥，不直接读取用户任意磁盘路径，不运行自由 shell 命令。

界面以 React 组件和数据文件分离，后续 Electron 版可以复用业务组件，并用本地 API 替换静态 JSON。Sites 发布仅托管当前网页原型，不具备访问本机 TDX 或 Harness 的能力。

源代码检查包括完整构建、TypeScript 检查、行情样本统计及 53 项技能唯一性检查；没有宣称已完成浏览器端操作验收。
