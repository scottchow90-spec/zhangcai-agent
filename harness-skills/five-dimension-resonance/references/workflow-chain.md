# 盘后研究全链路工作流

> 从复盘到明日观察计划的完整执行链路。

---

## 一、链路总图

```text
盘后深度复盘 daily-review
  → 五维主升共振选股
  → Top10 五维信号表
  → 飞龙波段分布
  → 风险剔除/降级名单
  → Top3 个股深度分析
  → 风险预警
  → 明日观察计划
```

## 二、各步骤说明

### 步骤1：盘后复盘

必含：核心结论、数据状态栏、指数与风格、情绪温度(0-100)、五维共振前置模块。

### 步骤2：五维主升共振

从通达信自定义板块“飞龙在天”读取 `C:\new_tdx_mock\T0002\blocknew\FLZT.blk` 的全部个股作为候选池，扫描五套公式，输出Top10五维信号表。其他流程不变。

### 步骤3：Top10五维信号表

|---|---|---|---|---|---|---|---|---|---|---|---|

每列必须给出明确结论。

### 步骤4：飞龙波段分布

统计Top10中各波段标签数量：低位转强、主升健康、高位钝化、高位背离、退潮确认。用于判断主线处在启动/发酵/高潮/退潮哪一阶段。

### 步骤6：Top3深度分析

含五维信号表、波浪理论、基本面风险背景、资金、风险、V6.1短线26因子评分、操作观察计划。基本面只作风险背景，不得正向加分。

## 四、输出原则

1. 先结论，后证据
2. 先五维信号表，后展开分析
3. 先主线，后个股
4. 先风险，后计划
5. 所有报告必须有数据来源清单和"不构成投资建议"声明

## 五、云端使用说明

- 本地环境：blk→TQ六公式→iFinD→AI评分→报告。
- 非本地环境：只有在26因子、7条硬闸、15项风险及全局契约哈希均可复算时才允许评分。
- 缺少任一必需数据时记0且不重归一；缺少权威评分契约或候选覆盖时直接 `DATA_REQUIRED`，禁止按中性3星补分。
