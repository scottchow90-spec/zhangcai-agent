# 云端环境适配方案

> 本技能设计为本地/云端双模运行。云端Codex没有通达信TQ、没有iFinD本地配置、没有本地blk文件时，按以下方案降级使用。

---

## 一、数据依赖分级

| 等级 | 数据项 | 本地方案 | 云端降级方案 |
|---|---|---|---|
| 🔴必选 | 股票代码、名称、行情(现价/涨跌幅) | TQ snapshot | 用户提供纯文本 |
| 🔴必选 | K线数据(OHLCV) | TQ get_market_data | 用户提供或外部接口 |
| 🟡重要 | 大牛线公式输出 | TQ formula_process_mul_zb | 用户提供或从K线手动计算MA/趋势 |
| 🟡重要 | 飞龙在天公式输出 | TQ formula_process_mul_zb | 用户提供或从K线计算波段位置 |
| 🟡重要 | 游资/机构/庄家资金 | TQ formula_process_mul_zb | 用户提供或从公开资金流向替代 |
| 🟢补充 | 基本面/财务 | iFinD MCP | 用户提供或公开财报 |
| 🟢补充 | 新闻/公告/题材 | iFinD search_news | 用户提供或公开来源 |
| 🟢补充 | 龙虎榜 | iFinD/同花顺 | 用户提供或当日无法获取按中性处理 |

---

## 二、云端交互模式

### 模式A：用户提供完整公式数据

用户在云端粘贴TQ导出的JSON/CSV数据，AI按五维模型评分。

触发词示例："帮我用五维共振分析这些股票，附TQ数据如下：..."

AI操作：读取→解析→五维评分→输出信号表。

### 模式B：用户提供K线+基本行情

用户只给K线OHLCV，AI从K线估算关键指标，标注估算项。

AI操作：从K线估算波段位置、主力资金→降低置信度标注→给近似评分。

### 模式C：纯知识问答

用户问某个公式的逻辑、某个信号的触发条件、某个维度的评分规则。

AI操作：从公式源码和解读文件回答，不依赖实时数据。

## 三、云端不可用时的标注规范

报告中必须使用以下标注：

```text
✅ 数据完整：[数据项]来自[来源]
⚠️ 数据估算：[数据项]从K线/公开数据手动估算，置信度降低
❌ 数据缺失：[数据项]未提供，按中性3星处理
➖ 不适用：[数据项]不适用于当前分析场景
```

---

## 四、本地环境特有工具

以下仅供本地使用，云端不触发：

- `tq.get_market_snapshot()` — TQ实时快照
- `tq.get_market_data()` — TQ K线
- `tq.formula_process_mul_zb()` — TQ副图公式
- `tq.formula_process_mul_xg()` — TQ选股公式
- `get_stock_info/get_stock_financials/search_news/search_notice` — iFinD MCP
- 本地通达信 `blocknew/*.blk` 板块文件 — 本地选股池文件（云端不依赖该路径）

云端不会调用这些，但可以通过用户提供的数据达到等效效果。

## 五、云端首次导入测试

导入本技能后，在云端发送以下验证消息即可自检：

```text
请输出五维主升共振的信号等级定义、五套公式的名称和定位、飞龙波段的6个区间和含义。
```

AI应能正确输出，证明封装知识已完整加载。
