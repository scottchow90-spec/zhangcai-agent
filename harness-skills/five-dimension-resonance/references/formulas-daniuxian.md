## 二、核心字段映射

### 趋势判断字段

| 字段 | 公式 | 含义 |
|---|---|---|
| 主趋势线 | EMA(EMA(C,10),10) | 核心趋势生命线 |
| EMA9 | EMA(C,173) | 慢速均线(长期趋势) |
| EMA10 | EMA(C,193) | 更慢均线 |
| EMA11 | EMA(C,213) | 最慢均线 |
| MA5/10/20/60 | MA(C,5/10/20/60) | 标准均线 |
| 流通市值 | FINANCE(40)/100000000 | 流通市值(亿元) |
| 涨停价/跌停价/明涨停/明跌停 | ZTPRICE/DTPRICE | 价格边界 |

### 买卖信号字段

| 信号 | 触发条件 | TQ返回 | 含义 |
|---|---|---|---|
| 庄进 | 股价<机构成本+控盘转升+资金线金叉 | OUTPUT序号需验证 | 主力进场 |
| 庄出 | 股价>机构成本+控盘下降+资金线死叉 | OUTPUT序号需验证 | 主力出货⚠️ |
| 点火 | CROSS(EMA3,EMA21) | OUTPUT61含'←点火' | 启动信号 |
| 抄底 | DDX二次探底+MACD金叉 | 位置13附近 | 超跌反弹 |
| 龙回头 | 涨停后回踩操盘线/震仓线 | OUTPUT编号待确认 | 强势股回踩 |
| 妖股 | 暴利形态/平台突破+涨停 | DRAWICON位置7 | 高弹性标的 |
| KDJ起爆 | KDJ三线多头金叉+涨停+非ST+0~80亿 | 辅助信号 |
| 卖点 | HHV(DX,2)=HHV(DX,7)+DX>50+死叉 | DRAWICON位置6 | 卖出信号 |

### 辅助信息字段

| 字段 | 内容 |
|---|---|
| 概念版块 | 行业板块+地域板块 |
| 主题投资 | 概念板块 |
| 主营业务 | 行业板块 |
| 公司亮点 | 行业板块 |

## 三、多空状态判断

| 状态 | 条件 |
|---|---|
| 红K(多头) | EMA5 > EMA20 |
| 绿K(空头) | EMA5 < EMA20 |
| 白K(过渡) | EMA5 > EMA20但EMA5 < EMA10，或EMA5 < EMA20但EMA5 > EMA10 |
| 大牛线上涨趋势 | EMA9 > EMA10 > EMA11 |
| 大牛线下跌趋势 | EMA9 < EMA10 < EMA11 |

## 四、K线变色逻辑

| K线颜色 | 条件1 | 条件2 | 含义 |
|---|---|---|---|
| 红色实体 | EMA5>EMA20 | 收盘>开盘 | 多头+阳线 |
| 红色空心 | EMA5>EMA20 | 收盘<开盘 | 多头+阴线(假阴) |
| 绿色实体 | EMA5<EMA20 | 收盘<开盘 | 空头+阴线 |
| 绿色空心 | EMA5<EMA20 | 收盘>开盘 | 空头+阳线(假阳) |
| 白色 | EMA5与EMA20交叉附近 | — | 过渡/震荡 |

## 五、信号分级

| 等级 | 条件 | 结论 |
|---|---|---|
| 强 | 主趋势线上行+站上趋势线+点火/庄进 | 进入观察池 |
| 中 | 趋势线走平+股价站上趋势线 | 等飞龙和资金确认 |
| 弱 | 趋势线下行或股价跌破趋势线 | 降权 |
| 风险 | 庄出/卖点/跌破主趋势线 | 剔除或风控 |

## 六、标准化输出

分析个股时的大牛线标准输出：

```text
大牛线：趋势向上/走平/破坏 | 站上/跌破主趋势线 | 点火/庄进/庄出/无 | 大牛线上涨/空头/混合 | 流通市值XX亿
```

本地依赖：需要通达信TQ的`get_market_snapshot`和`formula_process_mul_zb`接口。

云端替代方案：如无TQ，可从MA5/10/20/60手动判断趋势，从涨跌幅和题材判断信号强度。
