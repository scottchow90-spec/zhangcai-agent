# 机构资金监控 公式子系统映射

## 16子系统完整清单

### 第一层：大单总口径

1. **大单动向** — `(LARGEINTRDVOL-LARGEOUTTRDVOL)*10000/FINANCE(7)`
   - 外显输出，NODRAW
   - 依赖动态函数 LARGEINTRDVOL / LARGEOUTTRDVOL
   - 正值=大单方向偏正，负值=偏负

2. **NOTEXT1** — `MA(大单动向,10)*3`
   - 外显输出，NODRAW
   - 10日均线×3 平滑线
   - 大单动向历史为空时，NOTEXT1 也为 null

3. **OUTPUT3** — `STICKLINE(大单动向>0,...)` 正向柱
   - 图形输出线，由 TQ 返回为 OUTPUT3
   - 大单动向>0 时=1.00，否则=0.00

4. **OUTPUT4** — `DRAWGBK(CLOSE>0,...)` 背景层
   - 图形输出线，由 TQ 返回为 OUTPUT4
   - 不是资金信号！仅表示背景绘制
   - ⚠️ 必须与游资资金监控的 OUTPUT4（正向买方柱）区分

### 第二层：L2四档净量内部变量

5. **X_1** — `(L2_VOL(0,0)-L2_VOL(0,1))*VOL/10000` 第0档
   - `:=` 内部变量，未外显
   - 经 EMA20+CAPITAL归一 → 机构大单进

6. **X_2** — `(L2_VOL(1,0)-L2_VOL(1,1))*VOL/10000` 第1档
   - `:=` 内部变量，未外显
   - 经 EMA20+CAPITAL归一 → 大户大单进

7. **X_3** — `(L2_VOL(2,0)-L2_VOL(2,1))*VOL/10000` 第2档
   - `:=` 内部变量，未外显
   - 经 EMA20+CAPITAL归一 → X_5（也未外显）

8. **X_4** — `(L2_VOL(3,0)-L2_VOL(3,1))*VOL/10000` 第3档
   - `:=` 内部变量，未外显
   - 经 EMA20+CAPITAL归一 → 散户资金进

### 第三层：资金分层外显指标

9. **机构大单进** — `EMA(X_1,20)*60/CAPITAL`
   - 外显输出，NODRAW, COLORRED
   - >0 = 机构大单方向正；<0 = 机构大单方向负

10. **OUTPUT6** — `STICKLINE(机构大单进>0,...)` 正向柱
    - 图形输出线，TQ 返回为 OUTPUT6
    - 机构大单进>0 时=1.00，否则=0.00

11. **机构大单出** — `机构大单进<0`
    - 外显输出，NODRAW
    - 机构大单进<0 时=1.00，否则=0.00

12. **大户大单进** — `EMA(X_2,20)*60/CAPITAL`
    - 外显输出，NODRAW, COLOR00AACC
    - >0 = 大户大单方向正；<0 = 大户大单方向负

13. **X_5** — `EMA(X_3,20)*60/CAPITAL`
    - `:=` 内部变量，不能外显
    - ⚠️ 源码未外显，禁止编造数值

14. **散户资金进** — `EMA(X_4,20)*60/CAPITAL`
    - 外显输出，NODRAW, COLORGRAY
    - >0 = 散户/小档方向正；<0 = 散户/小档方向负

15. **小单资金出** — `大户大单进<0`
    - 外显输出，NODRAW
    - ⚠️ 字段名是"小单资金出"，但源码判定条件是大户大单进<0
    - 大户大单进<0 时=1.00，否则=0.00
    - 必须严格按源码解释，不能替换条件

16. **中轴线** — `0`
    - 外显基准线，POINTDOT

## 关键调用限制

- LARGEINTRDVOL / LARGEOUTTRDVOL / L2_VOL 均为动态/L2函数
- 当前运行态通常只能返回最新1-2日的动态值
- 历史日期多为 null，不可补全
- 不能用日线 OHLCV 强行复算这些动态函数

## 正确调用口径 ⚠️⚠️⚠️

### ✅ 正确：直接 formula_zb
```python
tq.initialize('C:\\new_tdx_mock')
tq.formula_set_data_info('301372.SZ', count=40, dividend_type=0)
result = tq.formula_zb('机构资金监控', '301372', xsflag=2)
```

### ❌ 禁止：formula_process_mul_zb 批量口径
`formula_process_mul_zb` 对本公式（依赖 LARGEINTRDVOL/LARGEOUTTRDVOL/L2_VOL）的返回值与通达信公式界面显示值不一致，**禁止用于本公式分析**。
