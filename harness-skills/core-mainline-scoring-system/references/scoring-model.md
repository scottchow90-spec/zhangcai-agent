| 评分项 | 权重 |
|---|---:|
| 市场强度 | 15 |
| 涨停广度 | 15 |
| 原梯队质量 | 10 |
| 精确3/2/1梯队完整性 | 10 |

| 资金结构 | 15 |
| 已核验催化 | 10 |

必需字段缺失时决策分固定为0且不重新分配权重。九项原始分完成后独立执行：

1. 至少各有一只精确3连板、精确2连板和精确首板，4板以上不能替代精确3板。
2. 可靠匹配的本地通达信完整成分股数量严格大于100只，100只也不通过。

## 收盘确认层

九项原始分和两道原硬门槛全部通过后，板块还必须同时满足：

| 收盘确认项 | 阈值 |
|---|---:|
| 原始分 | 不低于60 |
| 当日板块排名 | 前5 |
| 涨停股占全市场涨停股比例 | 不低于8% |
| 短线侠与连板网当日逐股样本覆盖 | 不低于80% |
| 可解析首次/最终封板时刻与开板次数的样本 | 不少于3只 |
| 板块可解析分时样本覆盖率 | 不低于60% |
| 相对当日市场的收盘质量信号 | 四项中至少两项通过 |

四项收盘质量信号均使用同日全市场涨停池作为动态基线，不使用历史固定结论：首次封板不晚于10:30的比例不低于市场、零开板比例不低于市场、最终封板不早于14:30的比例不高于市场、封单额/当日成交额不低于市场。

短线侠涨停池字段必须固定解释为：第3列封单额、第4列开板次数、第5列最终封板时刻、第8列当日成交额、第9列流通市值、第12列首次封板时刻。资金集中度和容量判断只能使用第8列成交额，不得使用第9列流通市值代替。

收盘确认失败时状态为 `CLOSE_UNCONFIRMED`，保留 `raw_score` 供审计，但决策分、星级和入选资格归零。前两名均收盘确认、质量信号数相同且原始分差不超过5分时，状态为 `AMBIGUOUS_CLOSE`，不输出唯一核心主线。

星级仅对证据、两道硬门槛和收盘确认全部通过的板块生效：5星要求分数不低于80、排名第1且涨停数大于15；4星要求分数不低于60、排名前三且涨停数大于8；其余档位由生产评分代码中的固定规则确定。
