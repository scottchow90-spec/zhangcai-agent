# 每日涨停板深度复盘报告模板（第七版，数据指纹与动态判断）

> 适用场景：每日盘后涨停板复盘、每日复盘、盘后复盘、今日复盘、市场宽度统计、涨停池方向统计、前排样本复核、次日观察计划和观察池。

> 硬规则：第0章按当次数据选中的结论节点生成分类矩阵；第1-16章各保留一段动态判断和一段关键数字，不使用统一结论包装，不重复其他章节判断。

> 合并规则：每日复盘的指数、成交、涨跌家数、市场宽度、次日计划、观察池和昨日复核并入本模板现有章节，不新增第二套“每日复盘”章节，不重复输出同一数据。

> 交付红线：退市股不得进入任何可见表格、统计或结论；正文不得出现拉丁字母，内部状态、情景键、公式字段和行业缩写必须使用中文显示名。
