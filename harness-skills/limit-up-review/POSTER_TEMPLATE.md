# 涨停板深度复盘 8K 海报模板

## 画布

- 固定尺寸：`7680 x 4320`
- 横向 16:9，PNG，RGB
- 背景：亮灰白，禁止近黑底、深色金融终端风格、密集小卡片和 4x4 网格
- 中文字体：微软雅黑；标题使用粗体，正文使用常规或粗体

## 字号

- 主标题：260 px
- 核心判断：150 px
- 分区标题：124 px
- 核心数字：180-220 px
- 重要正文：不低于 96 px
- 次要说明和风险提示：不低于 72 px

## 固定结构

1. 顶部标题带
   - 交易日期
   - “涨停板深度复盘”
   - 一句话核心判断
2. 全宽核心指标带
   - 涨停数
   - 上涨/下跌家数
   - 首板/连板
   - 最高板
   - 炸板/跌停
   - 封板率
3. 中部逻辑链
   - 普涨宽度
   - 首板扩散
   - 接力质量
   - 局部风险
4. 中部主线与资金
   - 第一方向数量、连板、占比和资金
   - 高位梯队
   - 资金覆盖与结构质量的区别
5. 底部次日四分支
   - 接力转强
   - 热点轮动
   - 亏钱扩大
   - 外部冲击
6. 页脚
   - 数据日期与来源边界
   - 教学研究用途和风险提示

## 内容规则

- 只读取本轮 `business_result.json` 已通过语义门的事实、推断和情景树。
- 不生成新股票推荐，不扩展观察池，不新增确定性买卖结论。
- 关键判断必须同时展示事实依据和次日验证阈值。
- 数据缺失时显示“不可用”，不得填零。
- 海报必须保留“普涨不等于短线全面转强”的条件化结论。

## 验收

- 输出必须为 `7680 x 4320`。
- 所有文本边界必须位于安全区内，无裁切、重叠或超出画布。
- 原尺寸和 1920 x 1080 缩略图都必须人工检查。
- 验证器必须核对尺寸、字号记录、边界、源文件哈希和非空图像。
