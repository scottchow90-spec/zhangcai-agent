# 优质赛道选股方法

## 主链

事件确认 → 赛道映射 → 赛道横截面评分 → 持续性硬门槛 → 个股初筛 → 主营确认 → 财务/估值/公告复核 → 纸面仓位。

## 赛道评分

收盘后如果本地日线尚未形成当日完整横截面，固定入口会通过腾讯批量行情补齐当日开高低收、成交量和成交额；覆盖率不足80%时直接阻断，不再把上一交易日标记为当日新鲜数据。盘中运行仍只标记为上一完整交易日的临时结果。

对每个明确映射的优质赛道计算七项指标：成分股平均1日收益、1日收益中位数、平均5日收益、上涨家数比例、涨停比例、量比中位数、成交额比中位数。每项转为全赛道百分位：

`赛道分 = 七项百分位均值 × 100 × 90% + min(10, 资讯命中数 × 2)`

严格赛道必须同时满足：

- 分数高于全体赛道分的中位数加中位绝对偏差；
- 至少一条本地资讯命中；
- 1日平均收益和中位数均为正；
- 上涨家数比例至少65%；
- 5日平均收益大于0。

回测信号按沪深300全历史交易序号固定锚定，每5个交易日取一个信号；不得从滚动窗口起点重新编号。每次运行还要比较当前日与前一日的共同信号，所有共同周期和交易必须完全一致。执行层回测未通过时，反转路线保持关闭。

## 个股评分与硬剔除

硬剔除：ST/*ST、股价低于2元、20日平均成交额低于5,000万元、接近涨停、5日涨幅超过30%、价格高于MA20超过25%。

`个股分 = 赛道分×50% + 趋势 + 动量 + 量能 + 波动 + 公司事件 + 角色候选 + 流动性 - 风险扣分`

角色候选分只用于排序。最终“核心公司”必须由最新主营收入构成确认：相关业务在一个分类中的收入占比至少10%。
个股原始分理论上限为110；输出的 `preliminary_score` 固定截断到0–100，
并保留 `preliminary_score_raw` 供审计。不同技能的分数不可横向比较。

## 公司级门槛

- 财务至少通过4/5：毛利率、负债率、营收同比、总资产周转率代理、存货周转天数。
- 总市值至少30亿元；PE-TTM必须在0到150；PB必须在0到15。
- 实时报价必须代码、名称和日期一致，且不得接近涨停或超过信号收盘价3%的追高线。
- 严重公司公告风险硬剔除；中等风险进入复核；例行关联资金往来审计不视为实际占款。

## 仓位

单只风险预算0.8%，单只上限20%，组合总暴露上限60%。止损使用2 ATR，最大距离8%。任何复核、剔除或赛道持续性失败都将仓位设为0。

## 解释边界

财务五维是结构化代理门槛，不等于完整基本面深研。实跑只对初筛前30名补充外部证据，因此观察名单不是全市场穷尽结论。执行层回测使用当前概念成员快照，存在幸存者偏差；回测状态为FAIL时不得用于真实资金。
