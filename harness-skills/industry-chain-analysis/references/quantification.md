# 本机数据与量化路由

## 基本规则

- 不调用原包中的 NeoData、WeStock 或任何未安装接口。
- 不把模型记忆、历史案例、搜索摘要或入口自检当作市场事实。
- 对价格、财报、公告、政策、新闻、产能、库存和市占率使用当前回合获取的证据，并记录检索时间。
- 需要浏览器交互时只使用用户的 Google Chrome；不切换到 Codex 内置浏览器。

## 本机路由

| 任务 | 首选路由 | 边界 |
|---|---|---|
| 产业链定义、政策和行业统计 | 政府、监管、行业协会、交易所和公司官方材料 | 优先一手来源，二手研报只能补充 |
| A 股证券身份、本地行情/K 线 | 先运行本技能 `tdx-smoke`，它只转入 `$tdx-local-hub` 固定入口 | 读取 TNF 名称映射与 vipdoc 日线，不直接挑选上游脚本 |
| 个股基本面、管理层、催化与估值 | `$stock-analysis` 的 `fundamental-research` 模式，加当前公开证据 | 契约审计不等于实际研究报告 |
| 事件到赛道再到纸面选股 | 用户点名“优质赛道选股”时使用 `$quality-track-stock-selection` | 本技能不得替代该执行器 |
| 用户点名其他股票流程 | 使用被点名技能的固定入口 | 不得自动路由到近似技能 |
| 没有匹配本机技能的数据缺口 | 公开一手来源和官方 API/页面 | 说明覆盖缺口，不虚构接口 |

## 证据最小字段

每项事实记录：

- `id`：证据唯一标识。
- `claim`：证据直接支持的事实，不写推断。
- `source_name`：来源主体或文件名。
- `source_date`：来源发布日期或报告期。
- `retrieved_at`：本回合获取时间，带时区。
- `source_locator`：URL 或本地绝对路径加定位说明。

推断写入分析 section，使用 `evidence_ids` 绑定支持它的事实。来源冲突时保留冲突并写入“未验证”，不得挑选性忽略。

## 常用取证映射

| 分析问题 | 需要的数据 |
|---|---|
| 价值链 | 分部收入/毛利、资本开支、议价权和现金转换 |
| 竞争格局 | 同口径 CR3/CR5、公司份额、客户集中度 |
| 周期 | 价格、库存、开工率、产能利用率、新增产能 |
| 技术路线 | 量产时间、成本、性能、良率、认证和专利 |
| 政策 | 原文、发布机关、生效日期和影响机制 |
| 需求 | 销量、出货、渗透率、下游资本开支和替代品 |
| 受益公司 | 主营占比、订单/产能、收入利润、现金流和反证 |

## 持久化

按 `references/evidence_schema.md` 组装 UTF-8 JSON，运行固定入口。A 股任务先让 `tdx-status` 对 TNF、日线和 `$tdx-local-hub` 收据完成哈希读回；最终只有 `status` 对 `input.json`、`result.json` 和 `report.md` 的当前 SHA-256 与大小全部读回一致，才可引用该次结果。
