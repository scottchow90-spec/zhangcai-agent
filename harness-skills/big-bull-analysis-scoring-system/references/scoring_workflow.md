# 执行流程

## 输入

- 默认板块名称：黄金点火
- 默认板块简称：`HJDH`
- 默认板块文件：`C:\new_tdx_mock\T0002\blocknew\HJDH.blk`
- 默认读取数量：每只股票最近三百个交易日

## 数据来源

1. 板块成分：通达信自定义板块文件。
2. 股票名称：本机通达信名称表。
3. 日线：通达信运行态行情接口，未复权。
4. 短线侠：现有公开数据集没有任意自定义板块逐股日线，不适用于本技能核心评分；不得拿热点榜、涨停池或板块统计代替逐股日线。

## 输出

- `ranking.json`：板块信息、统一评分日、五项分数、总分、硬条件、并列名次和数据校验信息。
- `poster.png`：明亮大字八千海报。

## 失败处理

- 板块文件不存在：停止并返回明确路径。
- 板块为空：停止并返回板块为空。
- 通达信运行态不可用：停止，不以旧快照冒充当前运行结果。
- 任一股票数据不足：保留该股票并标为数据不足，不删除成分。
- 海报验收失败：停止，不交付未通过的图片。

## 海报检查

1. 尺寸严格为 `7680 × 4320`。
2. 最小可见字号不低于 72 像素。
3. 平均亮度不低于 190。
4. 可见文字不含英文字母。
5. 可见文字不含用户禁用词。
6. 当前板块不超过十一只时，海报行数必须等于成分数量。
