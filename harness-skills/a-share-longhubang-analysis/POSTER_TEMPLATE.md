# 龙虎榜资金结论横版8K明亮大字模板

- 画布：7680x4320，浅灰白背景，深色正文，红色金额，蓝色席位辅助信息。
- 版序：先显示量化结论，再显示逐股证据；数据表不得占据全部信息层级。
- 结论维度：资金集中度、大资金主攻方向、代表席位风格、板块风格、三日持续性、上榜触发风格、证据边界。
- 结论写法：每条从本次结构化数据生成，同时包含当日对象、判断和可复算数字；禁止预置默认结论、固定措辞、兜底判断和“按净买额排序展示”之类同义反复。
- 固定字段：股票、净买额、代表席位、全席位公开游资、核心概念、三日标记；游资字段与代表席位字段语义分开，不能把任一非代表席位命中误写成代表席位类型。
- 本次两张交付按9股与其余股票分摊，并按4项与3项分配七类结论；不得漏股、漏结论或生成第三张。
- 禁词：“未识别”“未可靠识别”“其他主题”及任何不能追溯到本次数据的泛化结论；候选生成与最终验证均须硬阻断。
- 字号：标题320px；核心数字242px；正文228px；最小辅助文字160px。
- 完整预览：1080x608；正文至少32px、标题至少45px、辅助文字至少22px，每行最多22字，不允许裁切、重叠、缺字或暗色背景。
- 绑定：候选、预览、检查记录、交付工件必须持有相同结论哈希与结论维度清单。
