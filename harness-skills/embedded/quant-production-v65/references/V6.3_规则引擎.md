# V6.3 规则引擎冻结说明

V6.3继续保留平台主升、弱转强、龙回头、黄金点火四模型的核心技术结构和增量评分逻辑，不把行业改造变成重写整套策略。主要升级为：六维行业强度与驱动引擎、完整行业生命周期、消息时效和价格确认、13步不可跳工作流、参数邻域稳定性生产门、双源一致率数值聚合修复，以及黄金点火盘中成交额硬门修复。

## 四模型
1. 平台主升：20日首板、昨日强趋势、压缩平台、突破20日高点、强K、量价合格。
2. 弱转强：20日首板、趋势可修复、前三日弱势或昨日极端超卖、突破10日高点、重新站上20日线。
3. 龙回头：2~13日前存在封板，回撤4%~18%，当前重新突破前3日高点并恢复10/20日趋势。
4. 黄金点火：最近3日内3周期指数线与21周期指数线交叉，短长差继续扩大，压缩后突破前5日高点，非涨停、位置不过热。

## 增量评分
硬门通过后才评分，硬门本身不重复加分。
- 平台主升最高23分；
- 弱转强最高24分；
- 龙回头最高23分；
- 黄金点火最高25分；
- 四模型当前准入门槛均为10分，后续只能通过样本外验证冻结新阈值。

行业首先作为硬门决定“能否交易”，硬门本身不再重复给分。只有行业分**超过当前市场所要求的硬门**才计“行业超额强度”增量分：每高出门槛4分+1，最多+5；高潮/分歧/退潮不享受此增量。极弱市平台主升中的锁筹已经是硬门，因此该场景锁筹也不重复加5分。

## 多模型共振
四模型独立保留全部标签。排名优先级：共振模型数 > 已触发模型最高分 > 股票代码。显示主模型只用于展示，不能覆盖其他同时触发模型。

## 多尺度支撑压力
保留60/120/250日因果区间，全部只使用当前日前历史极值。禁止退回单一120日版本。

## 盘中实时
仅10:00~11:30、13:00~15:00运行。使用实时现价/开高低、实时量比、实时换手、实时成交额和默认5分钟前稳定价。禁止线性外推全天量比，禁止复用同日旧未完成K线。

通用实时量比1.05~3.50、实时换手0.3%~18%、实时成交额>=3000万元。黄金点火量比1.15~2.80、换手0.5%~15%，并同样必须满足实时成交额>=3000万元。

## 三态
PASS / FAIL / UNKNOWN。只有“缺失字段确实可能改变候选结论”才传播UNKNOWN。UNKNOWN上卷为全局BLOCKED；BLOCKED不得写入严格生产样本。

## 正式授权与生产成熟度
AUTHORIZED只代表本次数据闭合。PRODUCTION_READY还必须通过滚动样本外、最终封存、因子消融、参数邻域稳定、盘中存活率和双源价格一致率等生产门。
