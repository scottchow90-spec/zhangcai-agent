# V6.5 固定完整输出模板

正式`execute`固定保留**十段一级结构**，不允许以“精简”为理由删除：
1. 核心状态；
2. 不可跳步工作流执行审计（必须13/13记录，N/A或BLOCKED也要记）；
3. 行业六维强度、生命周期与消息驱动；
4. 四模型独立结果（候选必须展开四模型硬门、分数和增量证据，禁止只报总分）；
5. 多模型共振结果；
6. 正式候选/阻断预览；
7. 实时UNKNOWN传播与主要淘汰原因；
8. 数据、回归与反偷工减料审计；
9. 量化生产定型状态（必须同时显示已授权归档、已成熟、未成熟样本数）；
10. 最终结论。

## 行业层强制输出
每个进入行业精算的行业必须展示：行业总分、生命周期、覆盖率、六维分、结构惩罚、负面事件风险、消息证据及交易日龄。消息检索失败必须显示异常，禁止写成“无消息=0分已核验”。

## UNKNOWN强制语义
- 潜在候选 + 关键字段缺失 => UNKNOWN => BLOCKED；
- 基本结构明确失败 + 其他字段缺失 => FAIL；
- 最终候选二源价格不可用 => 价格核验UNKNOWN => BLOCKED。

## 反偷工减料
不能只输出候选表；工作流、行业六维、消息证据、淘汰原因、审计、生产门都必须保留。任何一步没跑必须显示其状态和原因。

## 四模型逐模型证据强制项
对正式候选或BLOCKED预览候选，必须逐模型列出：硬门是否通过、模型分数、各增量证据分。禁止只给“主模型+总分”而隐藏另外三套模型的执行结果。


## V6.5 数据路由强制输出
第八节必须显示本轮数据路由（DIRECT_PUBLIC_API 或 WORKBUDDY_BRIDGE）以及主/二源来源标识。`DATA_BRIDGE_REQUIRED` 只允许作为WorkBuddy内部可恢复中间状态，禁止渲染成最终投资结果。


## V6.5 共识容灾追加字段
当 route=`CONSENSUS_RESCUE` 时，必须明确输出候选等级 `B_CONSENSUS_PRODUCTION`、主模型胜率/收益预测、未复权收盘价、成交额、当日涨跌、独立二源收盘价差、事件风险摘要、13步审计，以及“不得冒充原生四模型”的明示边界。
