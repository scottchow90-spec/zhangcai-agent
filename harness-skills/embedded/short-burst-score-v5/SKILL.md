# A股盘后短线爆发力评分系统 V5.0

## 本机Codex唯一入口

本技能已适配本机Codex，正式调用 `python scripts/codex_entry.py run -- --action prepare-analyze --data-root <目录> --trade-date <日期> --as-of <截止时间>`；离线诊断使用 `--action diagnose`；真实取数使用 `--action download`，默认复用本机数据入口，不要求Tushare密钥。离线诊断不能代替真实联调。已备快照使用 `--action analyze --input <快照>`。先读 references/workflow.md，严格区分合成安装调试与实际数据执行。

下文WorkBuddy命令仅为原引擎操作参考，本机统一入口由适配器代为调用；不得直接绕过股票目录和回执授权。结果固定写入本机F盘业务数据目录，仅用户明确批准的年度历史参考指定名单模式已登记独立工作流重放；其他模式仍不授予完整工作流完成。工作流完成不表示收益验证通过。

## 目标

本技能不是“龙虎榜净买额排序器”，也不是“连板高度排序器”。目标是：在T日收盘后，对候选强势股未来短线爆发潜力做**可审计的相对评分**，支持龙虎榜候选多选一，同时严格防止未来数据、盘中偷看、重复计分和坏历史样本误升级。

默认候选来自T日龙虎榜事件；用户明确指定股票名单时，以该名单进入同一原始审计和评分管线，市场/行业排名仍使用原参考全集。未上榜只在完整原始榜单核验后记为不适用，不制造榜单或买卖金额。默认模式合法空榜日输出空候选，市场分析照常执行。

**本次审计修订**：历史CSV入口仅生成分期描述统计，未实现冻结规则的独立逐折重放；当前版本不会输出“核心候选”，历史验证分项固定中性50分。高等级仍受市场、数据、风险上限约束。禁止手填JSON标志解锁生产资格。

## 不可绕过的硬边界

1. **时间冻结**：只处理T日收盘后且 `<= as_of` 的已公开数据。集合竞价、分钟线、盘中确认、T+1价格/收益和未来标签一律禁止进入日常评分。
2. **完整工作流不可少跑**：固定顺序为：**原始数据审计 → 物理时间截断 → 历史时点状态 → 市场总闸门 → 强势阶段 → 行业/题材持续性 → 市场/板块地位 → 价格透支 → 龙虎榜双窗口/席位/生命周期 → 盘后事件 → 历史样本 → 爆发力评分 → 风险否决与最终排序**。
3. **风险闸门先于评分**：北交所（默认）、ST/风险警示、退市整理、严重数据冲突、重大负面事件等可直接否决；不能靠高分覆盖硬风险。
4. **阶段不是固定等级**：首板、2板、3板以上、趋势强势的价值随市场周期变化。强进攻允许高连板获得更高适配度；正常轮动偏向2板；退潮更偏趋势强势，禁止再使用“2板永远高于3板、首板永远高于趋势”的固定字典序。
5. **技术面必须真正进入评分**：20日相对强度、20日均线斜率、20日突破强度、收盘位置、量能健康、启动位置、均线结构全部进入“技术动量”分项，禁止“计算但不用”。
6. **板块/地位只计一次主贡献**：板块状态、市场/板块地位、阶段-市场适配、板块相对强度与活跃度统一进入“结构地位”分项，避免连板高度通过多个字段重复隐性加权。
7. **龙虎榜是资金证据，不是最高优先级**：净买影响百分位、参与度、机构/营业部横截面强度、买卖平衡、席位成熟度、生命周期进入“资金质量”；大额净买不能越过技术、结构与风险。席位历史只用成熟样本，并在120个交易日窗口内默认按60个交易日半衰期衰减，评分端再按样本数向中性收缩。
8. **资金弹性独立建模**：自由流通市值百分位、换手率百分位、龙虎榜净买/自由流通市值百分位共同评价“资金推动弹性”；不是简单“小盘越好”。
9. **价格透支独立扣分**：3/5/10/20日涨幅、换手、成交额倍数、突破前高后的绝对扩张和ATR标准化扩张、连板高度、收盘位置、炸板弱收统一进入风险层，不与正向因子混成一团。
10. **盘后催化只能小权重进入**：只有截止 `as_of` 前公开、与公司直接相关且在同一事件行标为独立的催化（来源核验由输入方负责），才允许进入“事件驱动”小权重分项；中高风险事件进入独立扣分，重大风险/概念证伪可硬否决。
11. **历史样本必须看“质量”而不只看“数量”**：当前桶样本多不代表有效。核心候选升级必须同时满足：整套模型通过滚动样本外生产验收，且当前桶的5日爆发率Wilson下界、5日收益Bootstrap下界、相对基准超额Bootstrap下界均达到正向要求。历史桶为负时必须限制候选上限。
12. **评分不是概率**：`short_burst_score` 是0-100的同日相对爆发力评分。没有额外概率校准验证时，禁止把80分解释成80%上涨概率。
13. **缺数据必须降级**：缺完整市场因果特征、历史行业、席位明细、事件源或工作流覆盖元数据时必须显式降级，禁止少跑步骤后冒充生产结果。
14. **默认完整输出**：必须显示市场闸门、全候选评分表、六维分项、风险扣分、逐股证据链、历史桶强弱与硬否决原因。

## 六维评分结构

最终风险前基础分由六个0-100分项构成，权重全部在 `templates/default-config.json` 中公开，可审计、可回测替换：

- **技术动量 28%**：相对强度、均线斜率、突破、收盘位置、量能健康、启动位置、均线结构。
- **结构地位 25%**：市场/板块地位、阶段-市场适配、板块状态、板块相对强度、板块活跃度。
- **资金质量 22%**：龙虎榜净买影响、参与度、机构/营业部强度、买卖平衡、净买比例、成熟席位、生命周期改善。
- **资金弹性 10%**：自由流通市值适配、换手活跃度适配、净买/自由流通市值横截面强度。
- **事件驱动 5%**：只接受截止时点前已核验独立催化；无催化保持中性。
- **历史验证 10%**：当前相似历史桶的样本外表现；无合格历史模型保持中性，不伪造概率。

基础分之后再扣除价格透支、事件风险、龙虎榜负面/集中、市场高潮、异常弱承接等独立风险分，得到 `short_burst_score`。

> 这些权重属于V5.0透明先验结构，不宣称已经是统计最优参数。真正的参数优化必须使用滚动样本外回测，不允许根据单次结果手工追涨杀跌式调权。

## 核心候选规则

以下是保留的未来生产验收要求；本包尚未实现独立重放验证，因此现版不开放核心候选。高分本身不能成为核心候选，完整实现后也必须同时满足：

- 爆发力评分达到核心阈值；
- 市场至少处于强进攻/正常轮动；
- 整体历史模型 `production_qualified=true`，且该标志与自动验收明细一致；
- 当前相似历史桶达到“强正向”；
- 没有市场/数据覆盖上限和次新成熟度限制。

若当前历史桶为“负向/强负向”，即使样本数很大也必须限制候选等级，禁止再次出现“历史表现很差却因样本多升级”的旧错误。

## 标准生产命令

```bash
python scripts/workbuddy_entry.py audit-data --data-root data_raw --require-end 2026-09-10
python scripts/workbuddy_entry.py prepare-snapshot \
  --data-root data_raw \
  --trade-date 2026-09-10 \
  --as-of 2026-09-10T21:00:00+08:00 \
  --output snapshot.json
python scripts/workbuddy_entry.py analyze --input snapshot.json --format markdown
```

`build_snapshot()` 直接调用只生成 `raw-postmarket-v5.0-unverified`。只有 `prepare-snapshot` 完成文件结构、日期覆盖、关键数值与快照校验后才升级为 `raw-postmarket-v5.0-audited`。未审计快照会被强制降级。

## 历史研究

```bash
python scripts/build_history_model.py \
  --events labeled_events.csv \
  --cutoff 2026-09-10 \
  --output history_model.json
```

历史标签只允许在研究环境使用，与日常T日快照物理隔离。生成文件固定为 `research_only`、`production_qualified=false`；年份分期不是已经完成训练和独立样本外重放。详见 @references/research-validation.md。

详细数据纪律见 @references/data-contract.md；历史验证见 @references/research-validation.md；本次V5.0改造与反回归说明见 @references/deep-audit-merge-report.md。

## 用户明确替换历史市场参考

仅在用户明确要求时，market_reference.mode=yearly-limit-close-premium 使用所选股票近一年真实收盘涨停次数及每次涨停的下一交易日收盘溢价作独立历史参考，替换原120日历史市场参考。次日收盘严格高于涨停日收盘才算溢价，平收不算；未到下一交易日不入成熟样本，停牌单列。历史ST和真实除权参考用于涨停价判断。除权跨日保留两天原始收盘比较，并单列按真实除权参考价计算的等价结果。

该替换保留真实T日市场闸门、行业全集地位及原六维计分公式，历史统计不参与加分，不冒充原滚动样本外模型或生产资格；原历史验证分项在无合格模型时仍为50。年度逐事件标签放研究产物，日常快照只保留替换模式身份。原默认流程不变。

独立核验不接受生产者自填完成标志。公告来源仅覆盖已明确查询的公司公告接口；未登记新文档解读、新历史模型及原120日默认模式不得沿用本模式授权。
