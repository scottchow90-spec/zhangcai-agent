# WorkBuddy兼容性 V5.0

技能目录根部为 `SKILL.md`，其他资源位于 `references/`、`scripts/`、`templates/`。Python包、测试和数据适配器全部放在 `scripts/` 子目录。

日常 `analyze` 只依赖Python标准库；`prepare-snapshot` 的原始数据管线需要 pandas/numpy；真实Tushare下载器是可选能力。

V5.0保证：

- `prepare-snapshot` 不能绕过原始数据审计；
- 禁止盘中/竞价目录会直接拒绝；
- 只有 `raw-postmarket-v5.0-audited` 可声明完整生产快照；
- 手工/未审计快照按降级输入处理；
- 六维评分和风险扣分必须完整执行，不允许退回旧版字典序；
- 技术面、资金弹性和历史桶质量必须真实影响评分；
- 席位历史只使用成熟样本，120日窗口内默认按60个交易日半衰期衰减，且评分端继续做样本数收缩；
- 同分使用股票代码稳定排序，禁止输入顺序决定名次；
- 当前历史入口仅描述研究，缺独立规则重放证明，因此不开放核心升级，历史分项保持中性。
