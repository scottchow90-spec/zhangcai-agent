# A股短线爆发力评分系统：原包深度审计与修订

审计日期：2026-09-11。修订标识：5.0.1。保持原技能标识、压缩包顶层目录、命令入口和六维权重；修复回写原ZIP，不新增第二个安装包或本机安装实例。

## 审计范围与方法

检查原包全部37个成员，沿安装校验、下载、原始数据审计、单位转换、时间截断、行业归属、候选/席位、事件、历史研究、评分和报告逐层追踪。并行审查用于不同代码模块，主代理统一复核、集成和验收。

原包自带48项核心检查和17项自动测试全部通过，但不足以证明下列边界正确。已补充失败复现后修复；旧版“手填合格历史模型就升级”的测试改为必须拒绝，并保留负历史桶上限的独立逻辑验证。

## 确认的问题与处理

| 环节 | 原问题及后果 | 修复后的行为 |
|---|---|---|
| 盘后边界 | 接受盘中as_of；按输入时区日期而非上海交易日比较 | 快照与分析均按中国标准时间校验日期且不早于15:00 |
| 数值与输出 | NaN/无穷进入评分；缺席位统计输出非标准JSON NaN | 输入拒绝非有限值；输出缺失指标为null，严格JSON序列化 |
| 配置 | 负风险扣分可反向加分；全零/错拼权重及颠倒阈值被默许 | 配置结构、有限数值、权重和阈值校验 |
| 风险顺序 | 新股特殊池先于重大风险硬否决 | 硬否决优先，新股不能覆盖重大风险 |
| 板块状态 | 弱势条件提前吞掉退潮条件 | 先判退潮，恢复相应否决 |
| 证据等级 | 候选被降级但仍显示A级证据 | 等级随最终上限同步 |
| 缺失特征 | 技术/市值缺失被0或0.5占位后标为正常 | 保留missing_score_features，评分中性占位且限制到观察级 |
| 行业归属 | 历史区间无匹配时删除股票，扭曲统计 | 保留股票，报告T日实际映射率；关键行业缺失明确阻断 |
| 收盘位置 | 合法0值被or .5改成中性，弱收盘漏判 | 最低价收盘仍为0 |
| 龙虎榜窗口 | 三日分母使用最近三条股票记录，停牌时借入旧金额 | 使用市场最近三个交易日 |
| 席位匹配 | 主原因无匹配时借用别的原因；先去重丢掉合法窗口 | 先匹配代表原因，再去重；错窗口不借用质量/买一 |
| 指数单位 | 根据涨幅大小猜百分数或小数 | 严格遵循标准化小数契约 |
| 数据结构 | 重复行情、非法价格/成交额、静态重复/重叠关系漏检 | 增加主键、有限值、价格关系与历史区间核验 |
| 空数据 | 空CSV丢字段；空榜误当错误 | 合法空表保留字段；零候选仍运行市场流程 |
| 事件真假 | 文本false被bool()转成真 | 严格解析布尔值；非法值报错 |
| 事件归因 | 不同事件的独立标记与高质量分拼接 | 质量仅来自同一独立事件行 |
| 事件时间 | 无时区按UTC猜测；坏日期静默丢弃 | 必须明确时区，坏日期拒绝，晚于截止事件排除 |
| 事件覆盖 | 无字段空表也能声称有事件源 | 无结构空表拒绝；不存在的源保持缺失 |
| 历史资格 | 任意真值checks、伪折叠/哈希能解锁生产 | 严格验收字段与类型；本包历史入口固定仅研究参考 |
| 历史样本 | 重复事件虚增样本、未成熟标签可能进入研究 | 股票+日期去重拒绝，显式成熟日期截断，非法标签拒绝 |
| 统计独立性 | 将同日多股当完全独立样本，区间过窄 | 至少独立日期门槛；连续5个观察日整块重采样 |
| 下载缓存 | 指数文件存在就跳过新增日期；坏缓存永久复用 | 校验缓存、刷新请求范围并保留旧历史；当天重新获取 |
| 接口失败 | None可缓存成空榜；默认日期包含未来 | None重试失败即阻断；必要行情不得为空，默认截至当天 |
| 包完整性 | 空清单/漏列文件仍VERIFY_OK | 校验清单集合、文件数、大小、摘要和路径边界 |
| 自测与流程 | 固定测试名单漏掉新增测试；异常可跳过后报成功；分析改写输入轨迹 | 自动发现全部测试，失败非零；深拷贝轨迹，统一步骤与真实历史状态 |
| 依赖与说明 | 文档pandas>=2.0不支持使用中的include_groups；全市场/样本外表述超出实现 | 明确pandas>=2.2、pytest要求、龙虎榜候选范围与研究边界 |

## 必须保留的能力边界

1. 本次证明的是代码、工作流与离线安装包一致性；没有启动或接管WorkBuddy，没有验证其宿主实际安装/调用，也没有调用真实行情接口或使用凭据。
2. 实际候选为T日龙虎榜股票，不是全市场所有强势股扫描器。空榜结果为空，不补造候选。
3. 年份分期不等于训练或独立样本外重放。历史CSV生成research_only模型，日常历史分项中性50分；当前包不开放核心候选，手填JSON不能解锁。其余评分和风险流程可正常执行。
4. 六维权重为透明先验，保持28/25/22/10/5/10；没有真实回测数据时不声称优化了收益、胜率或最优权重。
5. 原始数据schema/时间/数值审计不证明第三方源真实完整。上游披露时点、历史可见性、规则冻结、交易成本、停牌/涨跌停可成交性以及概率校准仍需真实数据独立验证。
6. 原包中已有模板是示例，不作为真实市场结果。本次离线模拟数据仅在临时测试目录使用，不混入正式输入或交付结论。
