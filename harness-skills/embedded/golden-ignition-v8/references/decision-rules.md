# V8 三模型决策规则摘要

## 公共股票池

至少130根K线；排除ST、退市、北交所；收盘价>2；成交量>0。

## 模型A：平台/蓄势突破

目标是抓“压缩/蓄势后第一次有效突破”。V8不再把四K实体重叠、缩量、波动收缩等全部设为硬条件，而主要作为质量评分，降低过度过滤。

硬门槛：趋势至少一项转强、收盘在EMA20上、突破10日或20日高点、收阳、收盘位置≥0.70、归一化强度≥0.35、量比0.80～4.00、不过热。评分≥70确认。

## 模型B：龙回头

目标是抓“前期强势身份 → 发生洗盘 → 当前第一次再启动”。洗盘必须比最近强势身份更近，且洗盘距当前最多8个交易日。当前需短线强弱回升、收阳、趋势恢复、量能不过度、回撤受控。评分≥70确认。

## 模型C：第一次有效黄金点火 V8

### 1. 点火事件

`EMA3` 从下向上穿越 `EMA21` 只是事件。真正信号是本次事件后的**第一次有效确认**。

- 当日金叉：今天刚发生交叉。
- 次日首次确认：昨天金叉，但昨天没有完成有效确认。
- 第二日首次确认：两天前金叉，昨天仍保持EMA3>EMA21，且前两天都没有有效确认。

同一次金叉不得重复确认。

### 2. 有效确认

要求阳线、实体占日内振幅至少25%、收盘位置≥72%、归一化强度≥0.25、至少突破5日高点或归一化强度≥0.50、量比0.75～3.50。

### 3. 点火前状态

回到“真正金叉发生前一天”检查，而不是机械使用昨天：
- 相对EMA21归一化位置在 -0.50～0.40；
- 金叉前EMA21三日斜率归一化≥-0.15。

### 4. 继续扩张

今天EMA3必须继续上升，且EMA3-EMA21的差值继续扩大；均线张口归一化≤0.60。

### 5. 过热与可交易性

最近3日不得已有归一化强度≥0.70的高热日；前10日累计涨幅归一化≤1.80；相对EMA20归一化乖离≤1.60；跳空归一化在-0.50～0.75；一字板排除。

### 6. 评分

总分100：点火结构30、价格确认30、量能/可交易质量15、新鲜度/过热15、上方空间10。总分≥70且5日内没有更早黄金点火，才确认。

## 输出优先级

同股多模型同时通过时可以标注“多模型共振”，但分数不得互借。黄金点火只解释第一次有效启动，后续洗盘再启动优先解释为龙回头。
