# 数据字段与口径

## 最低必需字段

标准 CSV 至少包含：

| 字段 | 含义 | 必需 |
|---|---|---|
| date | 交易日期，YYYY-MM-DD | 是 |
| code | 六位股票代码 | 是 |
| name | 股票名称 | 建议 |
| open | 开盘价 | 是 |
| high | 最高价 | 是 |
| low | 最低价 | 是 |
| close | 收盘价 | 是 |
| volume | 成交量 | 是 |
| amount | 成交额，单位元 | 建议 |
| board | 板块：主板/创业板/科创板/北交所 | 建议 |
| is_st | 当日是否ST | 建议，历史回测强烈要求 |
| is_delist | 当日是否退市整理/退市状态 | 建议 |

脚本兼容常见别名：`time`→date，`raw_open/raw_high/raw_low/raw_close`→OHLC，`vol`→volume。

## 价格口径

- 同一次计算严禁把原始价、前复权、后复权混在同一套OHLC中。
- 盘后单日实跑优先使用目标日真实可交易OHLC。
- 历史回测如数据发生除权除息，应额外提供公司行动/除权标记并做成交约束；纯公式无法完整还原所有历史状态。
- 涨跌幅制度按目标交易日判断：科创板20%；创业板2020-08-24及以后20%，此前10%；普通A股10%。ST在股票池阶段排除。

## 数据完整性

- 每股至少130根有效K线，否则 `BASE` 不通过。
- amount 缺失时，流动性加分不得默认获得；其余模型可继续计算。
- name/board/status 缺失时不得默认“非ST/非北交所”。若可从代码/可靠证券主数据推断板块可使用；历史ST状态不能用当前名称替代。
- 硬门槛依赖字段缺失：标记“待核验”，不能列入确认名单。
