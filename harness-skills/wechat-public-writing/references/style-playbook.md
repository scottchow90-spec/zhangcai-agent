# 公众号写作风格手册

## 学习边界

- 固化语料：两个公众号各100条公开索引记录，共200条；直接阅读全文样本共4篇。
- 学习内容：标题、主题、摘要、结构逻辑、条件分支、叙述节奏和语言特征。
- 未验证：两个公众号后台连续历史无缺口；不能把200条记录表述为200篇全文逐字精读。
- 使用原则：只迁移抽象写法，不复制原句、署名、固定口头禅或可识别人设。

## 共同逻辑

1. 用时间锚点或单一冲突建立入口，第一屏先给结论。
2. 把盘面或事件拆成因果链，而不是堆砌资讯。
3. 用数字、阈值、板块对照和“如果A则B”降低理解成本。
4. 把判断落到观察、等待、留、减、止损或风险控制等动作。
5. 结尾从行情转向情绪、人性或纪律，形成陪伴感并交代风险边界。

## 行为技术型

- 逻辑顺序：总判断 → 空间/时间/方向 → 指数组件 → 阈值触发 → 仓位动作 → 纪律收束。
- 语言：短句、直白、口语化；常用问句、对比、二选一和时间词。
- 强项：把均线、压力位、小时级别、百分比止损等技术信息翻译为执行条件。
- 防偏：不能把单一技术指标写成确定性预测。

## 事件市场型

- 逻辑顺序：行情快照 → 最强分化 → 资金/杠杆因果链 → 编号消息 → 行业映射 → 仓位纪律 → 情绪安抚。
- 语言：事件化标题、短段落、反问和聊天感；用数字锚点约束情绪张力。
- 强项：每条消息追加作者判断、影响路径、反向情景和失效风险。
- 防偏：不得把传闻、情绪词或网络称呼替代事实来源。

## 融合型固定骨架

1. 标题：时间锚点 + 一个事件或判断。
2. 开头：一句总判断，再列2—4个关键数字或结论。
3. 拆解：从空间/时间/方向或指数/资金/政策/板块分层。
4. 映射：每条事实补充传导机制、受影响对象和反向条件。
5. 执行：明确观察位、等待条件、风险动作和失效标准。
6. 收束：用人性、情绪或纪律提醒结束，避免承诺收益。

## 原创表达约束

- 可以使用“先说结论”“关键在于”等通用过渡，但不要复刻来源账号的招牌句式。
- 第一人称只代表当前文章作者，不冒用原作者身份。
- 情绪词必须跟随事实或条件，不能连续堆叠。
- 标题只保留一个核心冲突，正文每段只承担一个信息任务。
- 没有新鲜来源时，将具体断言改写为假设、观察项或待验证问题。
