# Word 报告结构与验收

## 一、交付路线

- 最终只交付可编辑 DOCX。
- 使用 Microsoft Word 新建空白文档并完成打开、分页和 PDF 导出验证。
- 不使用旧业务报告作为模板。样式由程序重新建立；中央风险提示使用规定资源。
- 页面采用标准 A4，正文不得为压页而缩成难读小字。

## 二、固定页面顺序

1. 第一页：中央股票风险提示专页，文字必须与中央政策文件完全一致，不放任何业务内容。
2. 第二页：报告标题、实际交易日、数据截止时间、涨停总数、概念数及简短数据核验状态。
3. 概念总表：概念、涨停家数、最早首次封板时间、当日直接催化。
4. 各概念分表：先性质榜，后地位榜。每榜最多 10 只，不足时不补位。
5. 上午封板时间表：首次封板从早到晚，只含上午最终封住且收盘涨停的股票。
6. 龙虎榜净买入表：只含净买入额不低于 1 亿元的当日涨停股。
7. 核验证据：来源名称、抓取时间、交易日、定位信息和关键差异处理。

不存在符合项的章节保留标题，只写一条由本轮空结果生成的事实句，不插入历史样本或默认候选。

## 三、表格字段

### 概念总表

`概念｜涨停家数｜最早封板｜直接催化`

### 性质榜

`序号｜股票｜当天性质｜关键事实｜白话判断`

### 地位榜

`地位｜股票｜连续涨停｜首次/最终封板｜换手与成交｜白话理由`

### 上午封板表

`顺序｜首次封板｜最终封板｜股票｜主概念｜开板次数`

### 龙虎榜表

`顺序｜股票｜主概念｜买入额｜卖出额｜净买入额｜封板时间`

金额在正文统一使用亿元或万元并保留合适小数，底层结构化结果继续保留人民币元。

## 四、动态成文规则

1. 每个结论句必须先存在于本轮 `report_claims`，并绑定有效证据编号。
2. 句子只说能由表中事实支持的内容，例如“最早封板”“连续涨停高度最高”“同概念其后有几只跟随”。
3. 禁止写“有望、预计、通常、一般、值得关注、后市可期”等脱离事实的泛化话术。
4. 禁止出现“沿用上期、维持原判断、默认结论、固定结论、兜底判断”。
5. 股票、概念、数量、排名、时间和龙虎榜金额全部从本轮结构化结果填充，正文中不保留手写占位结论。
6. 报告可以得出空结果或没有总龙头；不为版面完整强造对象。
7. 每条可见结论必须在同一个 Word 段落中写成“结论：……依据：……反证：……”。结论和依据都要出现本轮数字事实，不能把三个部分拆进不同单元格或相邻段落。
8. 可见结论条数必须等于本轮 `report_claims` 的实际条数，不预设 4 条、10 条或其他固定数量。

## 五、防旧数据审计

- 文档创建前确认目标路径不存在旧文件；输出文件名含真实交易日和本轮时间。
- 记录本轮结构化结果的 SHA-256，并写入运行清单和文档属性。
- 从最终 Word 重新读出标题、交易日、股票代码、概念名和结论句，与本轮结构化结果逐项核对。
- 任何正文股票不在本轮涨停池、概念家数复算不一致、结论无证据编号或文档属性哈希不匹配，均阻止交付。

## 六、版式要求

- 清爽、克制、易扫读；以清晰标题、留白和表格层次体现精美，不放装饰性图片。
- 表头重复，列宽按内容设置，长理由允许自动换行；不得固定行高截断文字。
- 股票与时间列居中，理由与催化左对齐；数值列统一小数位。
- 不出现脚本、路径、编码、运行说明、验收自夸或任何制作过程文字。

## 七、交付硬闸

1. Word 初次写出后，先运行以下同类结论预检；不通过时直接修生成器，禁止先做导出、渲染或收据：

```powershell
python D:\C盘转移\日志\codex\skills\a-share-limit-up-leader-classification\scripts\codex_entry.py verify-docx --file <最终DOCX>
```

2. Word 能打开、计算页数并导出 PDF。
3. PDF 每页视觉检查通过：无空白业务页、重叠、截断、乱码、旧日期和错误标题。
4. 运行：

```powershell
python D:\C盘转移\日志\codex\skills\stock-delivery-risk-gate\scripts\stock_delivery_risk_gate.py gate --file <最终DOCX> --receipt <本轮目录>\stock-risk-gate-receipt.json
python D:\C盘转移\日志\codex\skills\stock-delivery-risk-gate\scripts\stock_delivery_risk_gate.py verify-receipt --receipt <本轮目录>\stock-risk-gate-receipt.json --file <最终DOCX>
```

以上任一环节失败都不得提供文件链接。任何正文修改都会使结论预检、Word 导出、逐页检查和股票风险收据全部失效，必须从第 1 步按同一顺序重跑。
