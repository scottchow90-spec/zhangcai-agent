# 首板涨停前选股工作流 v1.0
## 基于 TDX 全量 A 股 K 线数据 + TQ 公式

> 设计时间: 2026-06-24
> 版本: v1.0
> 设计目标: 在股票首板涨停前通过 7 大维度量化筛选提前识别候选股
> 回测结果: 9 个参考案例中 6 个通过 (67%)

---

## 一、工作流总览

```
Phase 0: 股票池构建 (全量 A 股 ~11738 只)
    ↓
Phase 1: 快速预筛选 (3 项 K 线初筛, 过滤 ~85%)
    ↓
Phase 2: 7 维度详细分析 (趋势/K线/量能/资金/风险)
    ↓
Phase 3: TQ 公式验证 (大牛线4.0 + 游资资金监控, 仅 Top 候选)
    ↓
Phase 4: 综合评分排序 → TOP N 候选
    ↓
Phase 5: 人工复核 → 最终决策
```

## 二、7 大维度详解

### 维度 1: 趋势线位置 (大牛线) ⚠️ 硬门

| 子项 | 计算方法 | 阈值 |
|------|----------|------|
| 股价在趋势上 | Close vs EMA30 | Close > EMA30 |
| 趋势向上 | EMA30 近10日斜率 | > 0 |
| 偏离幅度 | (Close-EMA30)/EMA30×100 | 0-15% |
| **得分** | 取决于偏离度 | 0-10 分 |

### 维度 2: K 线形态 (小阴小阳)

| 子项 | 阈值 | 得分 |
|------|------|------|
| 无大阳线/大阴线 | 单根实体 < 10% | 3 |
| 小 K 线为主 | 30日均实体 < 3.5% | 3 |
| 阳线多 | 阳线 ≥ 50% | 3 |
| 缓慢上推 | 20日涨 0-30% | 3 |
| **满分** | | **12** |

### 维度 3: 成交量 (温和放量 + 连续堆量)

| 子项 | 阈值 | 得分 |
|------|------|------|
| 放量中 | Vol5/Vol20 > 1.0 | 3 |
| 连续堆量 | ≥2天 Vol > 1.2×Vol20 | 3 |
| 量能温和 | 1.0 < Vol比 < 2.5 | 2 |
| 量能趋势 | 5日滚动斜率 ≥ 0 | 2 |
| **满分** | | **10** |

### 维度 4: 资金流 (买方意向)

**公式**: MF = (Close-Open) / Open × Volume

| 子项 | 阈值 | 得分 |
|------|------|------|
| 5日滚动累计为正 | 多数日 > 0 | 3 |
| 10日累计净流入 | Sum(10d) > 0 | 3 |
| 正向日占比 | ≥ 50% | 2 |
| MF 趋势向上 | 斜率 > 0 | 2 |
| **满分** | | **10** |

### 维度 5: 风险扫描 ⚠️ 硬门

| 风险项 | 阈值 | 后果 |
|--------|------|------|
| 短期涨幅过大 | 20日涨 > 30% | 剔除 |
| 单日大跌 | > 7% | 剔除 |
| 大幅波动 | 20日高低差 > 40% | 剔除 |
| 持续下跌 | EMA 斜率 < -0.01 | 剔除 |
| 量能萎缩 | Vol5/Vol20 < 0.5 | 剔除 |

## 三、综合评分体系

**总分 42 分** = 趋势(10) + K线(12) + 量能(10) + 资金(10)

**通过标准**: 趋势硬门 ✅ + 风险硬门 ✅ + 得分 ≥ 25/42 (60%)

## 六、参数速查

| 参数 | 值 | 说明 |
|------|-----|------|
| 趋势 EMA | 30 周期 | 主趋势线代理 |

| 最大实体 | 10% | 单根 K 线 |

| 阳线最低比 | 50% | 阴阳均衡线 |
| 堆量连续天 | ≥ 2 天 | 最小堆量 |
| 堆量倍率 | 1.2× | 超均量倍率 |
| 涨幅上限 | 30%/20日 | 风险红线 |
| 评分通过线 | 25/42 | 综合及格线 |
