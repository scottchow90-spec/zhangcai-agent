# 10项加权评分模型

下表10个项目都是软评分标准。总分为100分；缺失数据记0分且不重新归一化。六类风险硬排除在进入评分排名前执行，不占这100分。

当前 `speckzzdata.txt` 中公开沪深转债即使TNF无记录、本地债券或正股日线缺失、上市不足6个交易日或当日未交易，也保留在候选全集；除硬排除所需的当日SCR90变化或提前赎回状态无法核实会失败关闭/排除外，其余无法成立的周涨幅、溢价、筹码和五日换手等软分项记0，并强制标记RED供人工回避。TNF只作独立名称与存在性核验，不控制候选全集。`score_coverage_weight`按实际可用权重计算，行业、最强概念、正股趋势分别按30%、40%、30%的实际可用比例计入。

## 评分前硬排除

| 原因码 | 排除条件 |
|---|---|
| `bond_name_z_prefix` | 转债名称去除首尾空格并转大写后以ASCII `Z`开头 |
| `daily_gain_ge_10_and_volume_ratio_gt_4` | 当日涨幅 `>=10%` 且5日量比 `>4`；量比为当日成交量除以前5个交易日平均成交量，分母不含当日 |
| `scr90_change_1d_positive` | 当日90%筹码集中度减前一交易日值 `>0`，即集中度扩大 |
| `scr90_change_1d_unavailable` | 当日SCR90变化无法完整、有限且同截止日核实 |
| `turnover_5d_gt_1000` | 近5个交易日累计换手率严格 `>1000%` |
| `bond_close_gt_350` | 转债收盘价严格 `>350` 元 |
| `early_redemption_announced` | 截止日已有正式提前赎回/实施赎回/赎回暨摘牌公告 |
| `early_redemption_unverified` | 官方公告状态未知、覆盖不完整或无法逐债核实 |

同一转债可同时命中多个原因码。公告仅“预计触发/可能触发”或当前有效的“不提前赎回”不视为已公告提前赎回；公告来源、截止日、分页或逐债覆盖失败时，生产运行失败关闭。

| ID | 标准 | 权重 | 满分锚点或归一化规则 |
|---|---|---:|---|
| c1_price_activity | 近5日上涨强度 | 6 | `clip(5日涨幅/5%, 0, 1)`；下跌记0分 |
| c2_remaining_scale | 剩余流通规模 | 8 | 5亿元以内满分，5至15亿元线性递减 |
| c3_premium | 转股溢价率 | 12 | 10%以内满分；10%至50%递减至半分；100%归零 |
| c4_golden_ignition | 近期黄金点火 | 14 | 只认正股本地日线计算出的EMA3向上穿越EMA21；10个交易日内按新鲜度评分 |
| c5_feilong_cross | 飞龙在天20以下金叉 | 15 | 低位金叉按新鲜度和低位程度评分，临界结构仅部分分 |
| c6_youzi_inflow | 游资资金开始流入 | 15 | 正值25% + 继续增强35% + 5日内上穿0为40% |
| c7_scr90_convergence | 90%筹码峰收敛 | 6 | 精确最近6个基准交易日，以第1日减第6日；绝对缩小10个百分点占50%，相对缩小1/3占50% |
| c8_scr70_convergence | 70%筹码峰集中度收敛 | 8 | 精确最近6个基准交易日，以第1日减第6日；缩小3个百分点满分 |
| c9_sector_heat | 正股行业、概念与趋势 | 8 | 行业热度30% + 最强概念热度40% + 正股趋势30%；趋势由5日涨幅40%、EMA3>EMA21 30%、MA5>MA10>MA20 30%组成 |
| c11_turnover5 | 近5日累计换手率 | 8 | 150%满分 |

`c11`沿用已验收的兼容字段名。第10项业务标准是换手率；大牛线红色不是第11项评分，而是0分的完全同分优先规则。大牛线公式命中可保存在 `bigbull_formula_diagnostic_hits` 中供诊断，但不得改变c4分数。

SCR窗口固定为截止日所在基准日历的最近6个交易日，输入日期必须与这6日逐项完全一致并严格正序，数值必须有限。缺日、混入非交易日、重复日期、逆序、过期窗口或NaN/Infinity均视为窗口不完整，c7和c8记0分；不得改用“任意最近6条记录”或用非首尾记录比较。

所有有限浮点业务值先按固定12位小数、`ROUND_HALF_EVEN`规范化。排序固定为：按规范化后的 `score_total_raw DESC`，完全同分时 `big_bull_red_preference=True` 优先，再按可转债代码升序。摘要中的显示小数位不参与排名或独立复算。

风险层与评分分离：

- `RED`：本地债券/正股历史缺失或不同步、临近到期、临近最后交易日或其他风险否决，仅观察或回避。
- `YELLOW`：高价、高溢价、周跌超过10%或极小规模等警示，需人工复核。
- `GREEN`：未触发当前本地风险规则，但仍须核验公告、强赎、交易规则与实时价格。
