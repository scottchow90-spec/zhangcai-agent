# 顶级智库观点 DOCX 版式规范

本规范是正式 DOCX 的锁定模板绑定。生成器必须在业务 manifest 中记录本文件的绝对路径和 SHA-256。

## 页面与字体

- A4 纵向；页边距上/下 0.34 英寸、左/右 0.48 英寸。
- 中文使用 Microsoft YaHei，西文使用 Calibri。
- 标题 24 磅，一级标题 15 磅，二级标题 11.5 磅，正文不小于 8.4 磅。
- 正文控制在 4 至 8 页，不得出现空白页或不足 80 个非空白字符的独立页面。

## 内容与结构

- 至少 5 个原生可编辑表格、6 个可点击来源链接、20 个非空正文段落。
- 正文只显示中文智库名称和中文研究结论；网址仅作为隐藏超链接目标，不得显示 URL 或域名残留。
- 不得嵌入图片、截图或整页贴片；媒体文件数必须为 0。
- 不得出现过程说明、canary、自测、模板提示或确定性买卖指令。

## 验收

- `scan_docx_file` 必须返回 `CLEAN_PASS`。
- 页数优先使用 Microsoft Word 只读探测；不可用时允许 LibreOffice/PDF 或分页符估算，但必须在扫描结果中显式记录方法和警告。
- DOCX、生成器验证 manifest 和 `business_artifact_manifest.json` 必须位于同一 canonical run directory 并绑定大小与 SHA-256。
