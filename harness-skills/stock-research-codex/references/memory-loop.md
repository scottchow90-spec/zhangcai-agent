# Stock Research Learning Loop

## What To Learn

Learn process lessons, recurring user preferences, verified correction patterns, and reusable research workflows. Do not learn secrets, credentials, private tokens, or unnecessary raw financial data.

## Correction Flow

When the user points out a mistake or a stock-research outcome invalidates a prior answer:

1. Identify the concrete error: stale data, wrong ticker/security, unsupported inference, missing source, bad assumption, math error, or target-system confusion.
2. Correct the active answer first using fresh evidence.
3. Record a compact event in `D:\C盘转移\日志\codex\self_improvement\codex_self_improvement.sqlite` when the issue is material or repeated.
4. Promote only repeated or high-severity lessons into `AGENTS.md`, a skill update, or a memory update note.
5. Keep durable rules short and general. Prune duplicates during maintenance.

## Durable Surfaces

- Use the current thread for one-off thesis details.
- Use Codex memory for stable preferences and recurring research behavior.
- Use `stock-research-codex` for reusable stock-research workflow.
- Use `codex-self-improvement` for correction events, maintenance, and consolidation.
- Use automations for scheduled health checks and rule consolidation.

## Suggested Event Categories

- `process-rule`: research workflow or verification mistake.
- `preference`: stable output style or stock-research preference.
- `tool/config-fact`: verified local Codex, data source, or tool behavior.
- `reusable-workflow`: repeated stock-research procedure that should become a skill update.
